## Decisions Captured

- LRT-02 carry: Long-lived `activeConversation` reused across `chat()` calls (v1.8). Untouched by v2.0.
- v2.0: `LlmModelHelper` is a stateful runtime; the helpers themselves hold the engine. Repositories are stateless or only-own-DB. Crossing the boundary is the bug — `LlmHelperModule` uses `@Binds @Singleton` to bind interface → concrete.
- v2.0: `LiteRtLlmHelper.initialize()` wraps `EngineManager.switchToLiteRT` in `withContext(Dispatchers.IO)`. Caller's contract is "after the IO call completes", not "asynchronous from caller's POV".
- v2.0: `EngineManager.getCachedModelPath()` file copy is REMOVED. `EngineConfig.cacheDir` gets `context.cacheDir.absolutePath/<version>` (namespaced by `BuildConfig.LITERTLM_VERSION`) for mmap-only caching. Saves 1-3 GB/model + 3-10s cold start.
- v2.0: Cache directory capped at 500MB with LRU eviction by `lastModified`; cap is configurable via `AdvancedPreferences.cacheMaxSizeBytes`.
- v2.0: `EngineManager.handleTrimMemory` handles `TRIM_MEMORY_RUNNING_LOW` (soft cap) and `TRIM_MEMORY_RUNNING_CRITICAL` (unload + `evictAll`).
- v2.0: `LlmModelHelper.runInference` adds an `enableThinking: Boolean` flag. `LiteRtLlmHelper` maps to `parameters.reasoningEnabled` and strips `<think>...</think>` markers client-side when disabled. `LmStudioHelper` does the same.
- v2.0: `Skill` is a sealed value object with `SkillCategory { Tool, PromptTemplate }`. `SkillRegistry.all` is a `static val` (4 entries). Defaults to all-on via `SkillPreferences.enabledSkillIds` falling back to `SkillRegistry.all.map { it.id }.toSet()`.
- v2.0: `MessageEntity` gets a composite index on `(conversation_id, created_at)` via `@AutoMigration(12, 13)`.
- v2.0: `AppLifecycleProvider` backed by `ProcessLifecycleOwner`. `ModelDownloadWorker` reads `isAppInForeground` before `setForeground` — system notification is suppressed while the user is in the app looking at the in-app progress UI.
- v2.0: `installSplashScreen()` + 200ms cross-fade exit animation in `MainActivity` using `ObjectAnimator` alpha 1→0.
- v2.0: `NetworkModule` provides a separate `@Named("sse")` `OkHttpClient` with `retryOnConnectionFailure(false)`, `callTimeout(60.seconds)`, `readTimeout(0)`, 50MB on-disk cache. The default OkHttp client (downloads + REST) is unchanged.

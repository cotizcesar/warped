## Gaps

### Phase 35 — Gap 1: LiteRT-LM 0.12.0 → 0.13.0 API breakage not verified

**What's missing:** `./gradlew :app:assembleDebug` was not run. The 0.13.0 version may have introduced API breakage in `Engine.setNativeMinLogSeverity`, `Backend.CPU/GPU()`, `EngineConfig`, `ConversationConfig`, `Contents.of()`, `Message.system/user/model`, `OpenApiTool`/`tool()`, or `sendMessageAsync()`.

**Why it matters:** Without compile verification, the version bump may not actually work. The conversation-lifecycle refactor (LRT-02) is the only verified change.

**How to close:** Run `./gradlew :app:assembleDebug` in the user's dev environment. Patch any compile errors per the candidates listed in `35-PLAN.md` Task 2.

### Phase 35 — Gap 2: Unit test for conversation reuse not added

**What's missing:** No unit test (or instrumentation test) asserts that `activeConversation` is the same instance across two sequential `chat()` calls.

**Why it matters:** Without the test, the LRT-02 fix can regress silently in a future refactor.

**How to close:** Add a test to `app/src/test/java/com/warped/data/local/inference/LiteRTLmProviderTest.kt` (create if absent) using MockK to mock `EngineManager` and `LiteRTLmEngine`. Call `chat()` twice and assert the same `Conversation` instance is returned.

### Phase 35 — Gap 3: Multi-turn smoke test pending

**What's missing:** Manual verification that the engine now sees full message context across multiple turns. Requires a real `.litertlm` model + device/emulator.

**Why it matters:** This is the user-visible payoff of LRT-02.

**How to close:** Load a `.litertlm` model (e.g., Deepseek R1), send 3 sequential user messages, verify each reply is contextual.

- LRT-02: Long-lived `activeConversation` reused across `chat()` calls; `synchronized(this@LiteRTLmProvider)` protects lazy creation. `resetConversation()` is the public API to drop the conversation; called by `recoverEngine()`.
- HF-04: `LaunchedEffect(uiState.searchQuery)` syncs the local Compose state with the ViewModel state.
- CHAT-02: TopAppBar removed; drawer remains reachable via swipe at the NavGraph level.
- CHAT-08: Eager fetch — `fetchAllEndpointModels()` is called on every picker open (per user direction).
- ENDPT-05: Form restricted to `listOf(ProviderType.LM_STUDIO)`; OpenAI / Anthropic / Ollama / Custom removed.

- REC-03: Static `object RecommendedModels` with 8 hand-picked `.litertlm` models; no API calls.

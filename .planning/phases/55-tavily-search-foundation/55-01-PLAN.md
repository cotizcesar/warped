| app → logcat | Key material must never cross into logs |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-55-01 | Information disclosure | NetworkModule @Named(tavily) client | mitigate | Dedicated client with zero interceptors except redacted debug logger; per-call Bearer header; never log key or full body |
| T-55-02 | Information disclosure | TavilyApi ↔ endpoint clients | mitigate | AuthInterceptor never attached to Tavily client; endpoint keys never sent to api.tavily.com; Tavily Bearer never sent to chat endpoints |

| T-55-04 | Spoofing | Fuentes display of result URLs | accept | Display URLs verbatim in Phase 55 (no re-fetch); Phase 56 fetch step + Phase 58 OG add validation; rationale: no new spoof surface vs pasted-URL grounding |
| T-55-SC | Tampering | gradle installs | mitigate | Zero new dependencies in this plan — no installs, no audit rows required |

## Implementation

### 1. `:benchmark` module
Standard `androidx.benchmark:benchmark-macro-junit4:1.4.x` setup. Target `compileSdk = 35`, `minSdk = 28`, `targetProjectPath = ":app"`. Add `androidx.test.uiautomator:uiautomator:2.3.x` for the streaming-frame benchmark that scrolls a chat.

### 2. `ColdStartBenchmark.kt`
```kotlin
@RunWith(AndroidJUnit4::class)
class ColdStartBenchmark {
    @get:Rule val rule = MacrobenchmarkRule()
    @Test fun coldStart() {
        rule.measureRepeated(
            packageName = "com.warped",
            metrics = listOf(StartupTimingMetric(), FrameTimingMetric()),
            compilationMode = CompilationMode.DEFAULT,
            startupMode = StartupMode.COLD,
            iterations = 5,
        ) {
            pressHome()
            startActivityAndWait()
        }
    }
}
```

### 3. `StreamingFrameBenchmark.kt`
Launches the app, navigates to Chat, sends a prompt, scrolls while tokens stream, measures `FrameTimingMetric`. 5 iterations.

### 4. `SqlCipherBenchmark.kt`
Local JVM unit test (not Macrobenchmark). Uses `Room.inMemoryDatabaseBuilder()` for both SQLCipher-on (with a dummy passphrase) and SQLCipher-off paths. Measures insert + query for 1000 messages. Records the wall-clock time + heap delta. 10 iterations, take the median.

## Implementation

### 1. Room composite index (PERF-09)
- `MessageEntity` already has `Index(value = ["conversation_id"])`. Replace with `Index(value = ["conversation_id", "created_at"])`.
- Bump `AppDatabase` version to 13. New `MIGRATION_12_13`:
  ```kotlin
  val MIGRATION_12_13 = object : Migration(12, 13) {
      override fun migrate(db: SupportSQLiteDatabase) {
          db.execSQL("DROP INDEX IF EXISTS `index_messages_conversation_id`")
          db.execSQL("CREATE INDEX IF NOT EXISTS `index_messages_conversation_id_created_at` " +
              "ON `messages` (`conversation_id`, `created_at`)")
      }
  }
  ```
- Add `MIGRATION_12_13` to `Room.databaseBuilder(...).addMigrations(...)` in `DatabaseModule.kt`.
- Verify by writing an instrumentation test that runs `EXPLAIN QUERY PLAN SELECT * FROM messages WHERE conversation_id = ? ORDER BY created_at` and asserts it uses the new index.

### 2. AppLifecycleProvider (PERF-10)
```kotlin
interface AppLifecycleProvider {
    val isAppInForeground: Boolean
}

class ProcessLifecycleAppLifecycleProvider @Inject constructor() : AppLifecycleProvider, DefaultLifecycleObserver {
    private val lifecycleOwner = ProcessLifecycleOwner.get()
    private var foreground: Boolean = false
    init {
        lifecycleOwner.lifecycle.addObserver(this)
    }
    override fun onStart(owner: LifecycleOwner) { foreground = true }
    override fun onStop(owner: LifecycleOwner) { foreground = false }
    override val isAppInForeground: Boolean get() = foreground
}
```
Hilt bind in `AppModule`. `ModelDownloadWorker` reads it in `doWork` and skips the foreground notification if the app is foregrounded (since the in-app progress UI is already visible).

### 3. Splash screen (PERF-11)
- `gradle/libs.versions.toml`: `coreSplashscreen = "1.2.0-beta01"` (or latest stable, verify at execution).
- `app/build.gradle.kts`: `implementation(libs.core.splashscreen)`.
- `res/values/themes.xml`: define `Theme.Warped.Splash` that inherits from `Theme.SplashScreen` and sets `windowSplashScreenBackground` and `windowSplashScreenAnimatedIcon`.
- `MainActivity`:
  ```kotlin
  override fun onCreate(savedInstanceState: Bundle?) {
      val splash = installSplashScreen()
      splash.setOnExitAnimationListener { splashView ->
          val fade = ObjectAnimator.ofFloat(splashView, "alpha", 1f, 0f)
          fade.interpolator = AccelerateInterpolator()
          fade.duration = 200L
          fade.doOnEnd { splashView.remove() }
          fade.start()
      }
      super.onCreate(savedInstanceState)
      setContent { ... }
  }
  ```
- `AndroidManifest.xml`: change the `application android:theme` to `Theme.Warped.Splash` for the cold-start activity, and have `MainActivity` switch to `Theme.Warped` in `onCreate` via `setTheme(R.style.Theme_Warped)` before `setContentView` (if applicable).

# Plan 43-01: Compose — state split, ImmutableList, subcomposables, derivedStateOf (PERF-01..06)

**Phase:** 43 — Performance Convergence
**Requirements:** PERF-01, PERF-02, PERF-03, PERF-04, PERF-05, PERF-06

## Goal

Slice `ChatUiState` into 3 sub-states annotated `@Immutable`, migrate Compose boundary collections to `ImmutableList`, extract subcomposables in `MessageBubble` and `CodeBlock`, wrap eligible derivations in `derivedStateOf`, and add `key = { it.id }` to `LazyColumn` items.

## Scope

- `app/src/main/java/com/warped/ui/chat/ChatUiState.kt` (refactor — introduce 3 sub-states + aggregate)
- `app/src/main/java/com/warped/ui/chat/ChatViewModel.kt` (update state mutations to sub-states)
- `app/src/main/java/com/warped/ui/chat/ChatScreen.kt` (consume sub-states; pass to subcomposables; add LazyColumn key)
- `app/src/main/java/com/warped/ui/chat/components/MessageBubble.kt` (extract subcomposables: `MessageContent`, `MessageReasoningPanel`, `MessageActions`)
- `app/src/main/java/com/warped/ui/chat/components/CodeBlock.kt` (extract `CodeHeader`, `CodeLine`)
- `app/src/main/java/com/warped/ui/settings/SettingsUiState.kt` or wherever `trafficLightState` lives (wrap in `derivedStateOf`)
- `app/build.gradle.kts` + `gradle/libs.versions.toml` (add `kotlinx-collections-immutable:0.4.0`)

## Implementation

### 1. `ChatUiState` split (PERF-01)
```kotlin
@Immutable
data class ChatListState(
    val messages: List<ChatMessage> = emptyList(),
    val streamingContent: String = "",
    val streamingReasoning: String = "",
    val toolCallActive: String? = null,
    val isStreaming: Boolean = false,
    val codeTheme: SyntaxTheme = SyntaxTheme.MONOKAI,
    val codeFontScale: Float = 1.0f,
)

@Immutable
data class ChatInputState(
    val text: String = "",
    val attachedImages: List<Uri> = emptyList(),
    val audioBytes: ByteArray? = null,
    val isRecordingAudio: Boolean = false,
    val enableThinking: Boolean = false,
    val supportsThinking: Boolean = false,
)

@Immutable
data class ChatModelState(
    val selectedLocalModelId: String? = null,
    val selectedRemoteModelId: String? = null,
    val selectedRemoteProvider: ProviderType? = null,
    val localModels: List<LocalModel> = emptyList(),
    val remoteModels: List<ModelInfo> = emptyList(),
    val endpoints: List<Endpoint> = emptyList(),
    val isLocalModelLoaded: Boolean = false,
    val isLoadingModel: Boolean = false,
    val loadingModelName: String = "",
    val loadedInstanceId: String? = null,
    val activeModelId: String? = null,
    val supportsVision: Boolean = false,
    val generationParameters: GenerationParameters = GenerationParameters(),
    val error: ChatError? = null,
)

@Immutable
data class ChatScreenState(
    val list: ChatListState = ChatListState(),
    val input: ChatInputState = ChatInputState(),
    val model: ChatModelState = ChatModelState(),
)
```
`ChatViewModel.uiState: StateFlow<ChatScreenState>`.

### 2. ImmutableList migration (PERF-02)
- In `ChatScreen`, `BenchmarkScreen`, `PromptLabScreen`, `ModelsScreen`, `EndpointsScreen`, `SettingsScreen`: change `List<T>` to `ImmutableList<T>` at the composable boundary. Convert with `.toPersistentList()`.
- Map at the ViewModel: `combine(...).map { it.toPersistentList() }` or use the state-in sub-state collection.

### 3. Subcomposable extraction (PERF-03)
- `MessageBubble.kt` → split into:
  - `MessageBubble(...)` (top-level — receives ChatMessage + a small `MessageBubbleActions` callback object)
  - `MessageContent` (renders `text` + images + audio)
  - `MessageReasoningPanel` (extracted from existing inline block)
  - `MessageActions` (copy / retry buttons)
- `CodeBlock.kt` → split into:
  - `CodeBlockHeader` (language label + copy button)
  - `CodeBlockBody` (the `Canvas` / `Text` lines)

### 4. derivedStateOf (PERF-04)
- Locate the existing `trafficLightState` and `trafficLightStatusText` derivations. Wrap with `derivedStateOf { ... }` so they only recompute when their inputs change.
- If neither exists yet, log a TODO and skip (they may not exist in the current codebase — defer).

### 5. Hoisted state (PERF-05)
- Confirm `codeTheme` + `codeFontScale` are read once at the top of `ChatScreen` and passed to `MessageBubble` and `MarkdownText` (already done in 41-02; verify).
- Confirm `attachedImages` lives in `ChatInputState` (the new sub-state); pass as a stable `List<Uri>` to the input bar.

### 6. LazyColumn key (PERF-06)
- `ChatScreen.kt` currently uses `uiState.messages.forEach { ... }` inside a vertically-scrolling `Column`. If it switches to `LazyColumn` (recommended for very long histories), add `key = { it.id }`. For the current scrollable-Column, log a TODO noting the migration to `LazyColumn` is recommended if message counts grow >100.

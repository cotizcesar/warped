## Copywriting Contract

All copy in Spanish (existing convention). Sources: CONTEXT.md decisions + REQUIREMENTS.md FETCH-02/03 + existing v2.2 copy.

| Element | Copy |
|---------|------|
| Fetch progress chip (in-flight, N sources) | `Leyendo N de M…` — e.g. `Leyendo 2 de 4…`. Single-URL case keeps legacy `Leyendo página…`. |
| Chip accessibility description | `Leyendo N de M páginas. Pulsa Detener para cancelar la lectura.` (extends existing `Leyendo página. Pulsa Detener para cancelar la lectura.`) |
| Per-source omitted state | `omitida` — surfaced in progress state when a page dies but others ground the turn (FETCH-02). No silent drops: every pasted URL (up to cap of 5) is accounted as ok or omitida. |
| Fuentes heading | `Fuentes` (unchanged) |
| Fuentes items | `[N] {url}` in paste/first-seen order, `N` = count of grounded (ok) sources. Order == `[WEB CONTEXT 1..N]` block order. Long URLs wrap, never truncate (existing rule). |
| 6th+ URLs over cap | Silently ignored (deterministic first-5 rule from CONTEXT.md) — NOT surfaced as omitida; cap behavior is a contract detail, not user copy. |
| Model-only banner, all-fail offline | `Sin conexión. Respuesta solo del modelo, sin contenido de la página.` (unchanged, worst-case collapse: OFFLINE wins) |
| Model-only banner, all-fail fetch | `No se pudo leer la página. Respuesta solo del modelo — revisa tu conexión o pega otro enlace.` → pluralize page reference when M > 1: `No se pudieron leer las páginas. Respuesta solo del modelo — revisa tu conexión o pega otros enlaces.` |
| Destructive confirmation | None — no destructive actions in this phase. |

## UI Considerations

> State coverage for the two extended surfaces. Empty/error copy lives in
> `## Copywriting Contract` above — this section covers state behavior.

Applicable state considerations resolved: 6 covered, 1 backstop, 0 unresolved.

| Category | Element(s) | Status | Resolution / Reason |
|----------|------------|--------|---------------------|
| loading | fetch chip | ✅ covered | Chip shows `Leyendo N de M…` with spinner during fan-out; unmounts on completion/failure/Stop exactly as v2.2 (transient, never persisted, never a transcript message). Cancel via existing Stop (single cancel path cancels all in-flight). |
| partial | chip + Fuentes | ✅ covered | Partial grounding: ok pages ground the turn, dead links skipped in prompt but marked `omitida` in progress state; Fuentes renders only ok sources in block order. No silent drops. |
| error | model-only banner | ✅ covered | Banner renders ONLY when ALL pages fail/offline (never on partial). Per-source reasons collapsed to worst-case (OFFLINE wins over FETCH_FAILED); pluralized copy when M > 1. |
| zero-one-many | Fuentes list | ✅ covered | Zero sources renders no block at all (existing). One source = legacy single-item behavior. N sources (2–5) = numbered `[1..N]` list in paste order. |
| overflow | Fuentes list | ✅ covered | 5-URL cap: first 5 fetch, 6th+ ignored deterministically, Fuentes shows max 5 items. Long URLs wrap, never truncate. |
| long-text | fuente items | 🧪 backstop | Long-URL wrapping visual holds for N items in both themes — held-out visual check on device (same WEB-06 smoke precedent). |
| empty | Fuentes list | ✅ covered | Assistant message with no grounded sources renders no Fuentes block (unchanged). |

Out of scope (explicitly NOT this phase): bottom-sheet source preview, per-chat web toggle, persisted sources, retry affordance — all Phase 53/54.

## Implementation

### 1. `PromptLabScreen.kt` Markdown swap
Inject `AdvancedPreferences` via `viewModel`-less path: collect as `StateFlow` inside a small `rememberAdvancedPreferences()` helper, or pass `codeTheme` / `codeFontScale` into the screen from the parent composable.
- Easiest: read directly from the singleton's `codeTheme` and `codeFontScale` Flows inside `PromptLabScreen` via `LocalContext.current` + `hiltViewModel<PreferencesViewModel>()`.
- Simpler still: `PromptLabViewModel` exposes `codeTheme: StateFlow<SyntaxTheme>` and `codeFontScale: StateFlow<Float>` (collected from `AdvancedPreferences`). Pass into the screen.

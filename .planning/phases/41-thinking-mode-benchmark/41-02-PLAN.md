# Plan 41-02: Thinking Mode — Chat UI (Chip + Panel)

**Phase:** 41 — Thinking Mode + Model Benchmark
**Requirements:** THINK-04, THINK-05, THINK-06, THINK-07

## Goal

Surface the Thinking toggle as a chip in `ChatInputBar` (gated by per-model allowlist capability) and the reasoning trace as a collapsible panel in `MessageBubble`. Persist the toggle to DataStore.

## Scope

- `app/src/main/java/com/warped/ui/chat/ChatUiState.kt` — rename `reasoningEnabled` to `enableThinking`, add `supportsThinking: Boolean = false`.
- `app/src/main/java/com/warped/data/local/preferences/AdvancedPreferences.kt` (or equivalent) — add `thinkingEnabled: Flow<Boolean>` + `setThinkingEnabled(Boolean)`. Default `false`.
- `app/src/main/java/com/warped/ui/chat/ChatViewModel.kt` —
  - Collect `AdvancedPreferences.thinkingEnabled` into UI state.
  - Derive `supportsThinking` from `ModelAllowlistRepository.supportsThinking(activeModelId)` whenever model selection changes.
  - Add `toggleThinking()` method that flips DataStore preference (UI state updates via collect).
  - Pass `enableThinking = uiState.value.enableThinking && uiState.value.supportsThinking` to `LlmModelHelper.runInference()`.
- `app/src/main/java/com/warped/ui/chat/components/ChatInputBar.kt` — add `FilterChip` "Thinking" above the input row. Visible only when `supportsThinking == true`.
- `app/src/main/java/com/warped/ui/chat/components/MessageBubble.kt` — new private composable `ThinkingPanel(text: String, isStreaming: Boolean)` rendered above the markdown body when `message.reasoning?.isNotEmpty() == true`. Local `remember { mutableStateOf(isStreaming) }` for expanded state — default open while streaming, collapsed after stream completes.
- `app/src/main/java/com/warped/domain/model/ChatMessage.kt` — verify `reasoning: String?` field exists; add if missing.

## Implementation

1. **State + DataStore** (THINK-05 persistence): one new DataStore key, one new `Flow<Boolean>`, one new `suspend fun setThinkingEnabled`. Wired into `ChatViewModel` via `combine(...)` with existing state.
2. **VM gating** (THINK-06): `supportsThinking = allowlistRepo.supportsThinking(activeLocalModelId ?: activeRemoteModelId ?: "")`.
3. **Chip in `ChatInputBar`** (THINK-05): the chip sits above the row with the text field and send button.
   ```kotlin
   if (supportsThinking) {
       FilterChip(
           selected = enableThinking,
           onClick = onToggleThinking,
           label = { Text("Thinking") },
           modifier = Modifier.padding(end = 8.dp),
       )
   }
   ```
4. **Panel in `MessageBubble`** (THINK-04, THINK-07):
   ```kotlin
   if (!message.reasoning.isNullOrEmpty()) {
       var expanded by remember(message.id) { mutableStateOf(message.isStreaming) }
       LaunchedEffect(message.isStreaming) {
           if (!message.isStreaming) expanded = false
       }
       Surface(shape = RoundedCornerShape(8.dp),
               color = MaterialTheme.colorScheme.surfaceContainerLow) {
           Column {
               Row(verticalAlignment = Alignment.CenterVertically,
                   modifier = Modifier.clickable { expanded = !expanded }.padding(8.dp)) {
                   Icon(if (expanded) Icons.Filled.ExpandLess else Icons.Filled.ExpandMore, null)
                   Spacer(Modifier.width(4.dp))
                   Text(if (message.isStreaming) "Thinking…" else "Thinking",
                        style = MaterialTheme.typography.labelMedium)
               }
               AnimatedVisibility(expanded) {
                   Text(text = message.reasoning,
                        style = MaterialTheme.typography.bodySmall,
                        fontStyle = FontStyle.Italic,
                        color = MaterialTheme.colorScheme.onSurfaceVariant,
                        modifier = Modifier.padding(horizontal = 12.dp, vertical = 4.dp))
               }
           }
       }
   }
   ```
5. **Streaming reasoning bubble** in `ChatScreen.kt`: when `uiState.streamingReasoning.isNotEmpty()`, render a streaming `MessageBubble` placeholder with `reasoning = uiState.streamingReasoning, isStreaming = true`. Existing streaming bubble code structure adapts straightforwardly.

- During streaming, panel is expanded; after `Done`, panel collapses by default.
- User tap toggles panel freely.

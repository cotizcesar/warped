<objective>
Add `modelFormat: String` to the `LocalModel` domain model and update mappers to propagate it between domain and entity layers.

Purpose: Phase 6 added `model_format` to `LocalModelEntity` but the domain model and mappers were never updated. This gap means any code that creates or reads a `LocalModel` loses the model format information. Until this is fixed, `.litertlm` models cannot be properly distinguished from GGUF models in domain-level code.

Output: `LocalModel` domain class with `modelFormat` field, bidirectional mapper that preserves the value during entity<->domain conversion.

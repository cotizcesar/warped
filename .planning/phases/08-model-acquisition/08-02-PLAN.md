<objective>
Extend the Hugging Face API and repository layer to support search-by-format, enabling litert-community `.litertlm` model discovery alongside existing GGUF search.

Purpose: The current `HuggingFaceApi.searchModels()` hardcodes `filter="gguf"` as a default parameter. To discover `.litertlm` models from the litert-community, callers need to pass `filter="litertlm"`. This plan adds a format-aware overload while preserving backward compatibility — all existing callers (which don't pass a format) continue receiving GGUF results.

Output: `HuggingFaceApi`, `HuggingFaceRepository`, and `HuggingFaceRepositoryImpl` updated with format-aware search signatures.
</objective>

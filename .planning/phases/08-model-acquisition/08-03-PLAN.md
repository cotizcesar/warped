  <name>Task 1: Detect .litertlm format in ModelDownloadManager on download completion</name>
  <files>app/src/main/java/com/warped/data/local/download/ModelDownloadManager.kt</files>
  <action>
Modify the download-completion block in `ModelDownloadManager.startDownload()` (lines 179-195 in the existing code). After the download finishes, the current code unconditionally calls `GgufMetadataParser.parse(destFile)` which will fail on `.litertlm` files (non-GGUF magic bytes).

**Implementation (per D-03 context decision — set model_format based on file extension):**

Replace the metadata extraction block (lines 179-195) with:

```kotlin
val isLitertlm = localFileName.endsWith(".litertlm", ignoreCase = true)

val modelMetadata = if (!isLitertlm) {
    try {
        GgufMetadataParser.parse(destFile).getOrDefault(GgufMetadata())
    } catch (e: Exception) {
        GgufMetadata()
    }
} else {
    GgufMetadata() // .litertlm files have different binary format — use defaults
}

val localModel = LocalModel(
    name = localFileName.removeSuffix(".gguf").removeSuffix(".litertlm"),
    filePath = destFile.absolutePath,
    sizeBytes = destFile.length().takeIf { it > 0 } ?: fileSizeBytes,
    quantization = if (isLitertlm) "N/A" else modelMetadata.quantization,
    parameterCount = if (isLitertlm) "Unknown" else modelMetadata.parameterCount,
    architecture = if (isLitertlm) "LiteRT-LM" else modelMetadata.architecture,
    modelFormat = if (isLitertlm) "LITERTLM" else "GGUF",
    importedAt = Instant.now()
)

localModelRepository.saveModel(localModel)
```

Key changes:
- Detect `.litertlm` extension case-insensitively from `localFileName`
- Skip `GgufMetadataParser.parse()` for `.litertlm` files (avoid failure on non-GGUF magic bytes)
- For `.litertlm`: `quantization = "N/A"`, `architecture = "LiteRT-LM"`, `modelFormat = "LITERTLM"`
- For `.gguf`: existing behavior — parse metadata, `modelFormat = "GGUF"`
- Strip both `.gguf` and `.litertlm` suffixes from model name
- The `modelFormat` field is added per Plan 08-01

Existing download behavior (progress tracking, pause/resume, storage validation, WorkManager) is **unchanged** — `ModelDownloadManager` is already format-agnostic for the download phase. Only the post-download metadata extraction and DB save are format-aware.

private suspend fun loadCompatibility(models: List<HuggingFaceModel>): Map<String, Boolean> {
    val extension = ".${_uiState.value.activeFormat}"
    return models.map { model ->
        viewModelScope.async {
            val formatFiles = model.siblings.ifEmpty {
                huggingFaceRepository.getModelDetail(model.id)
                    .getOrNull()?.siblings ?: emptyList()
            }
            val isCompatible = formatFiles
                .asSequence()
                .filter { it.rfilename.endsWith(extension, ignoreCase = true) }
                .any { memoryChecker.canLoadModel(it.size.takeIf { s -> s > 0 } ?: it.lfs?.size ?: 0L) }
            model.id to isCompatible
        }
    }.awaitAll().toMap()
}

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-03 | Spoofing | ModelImportManager — filename extension | accept | Format detection relies on file extension. A malicious file renamed `.litertlm` would be stored with wrong format. Mitigation: file extension is the canonical format signal per D-03 context decision — alternative (magic bytes) requires a LiteRT-LM binary parser which doesn't exist. User controls which files they import. |
| T-08-04 | Denial of Service | ModelImportManager — large file import | mitigate | Android content resolver + `Dispatchers.IO` handle large files. `onProgress` callback enables UI to show progress. Storage validation is handled by `ModelDownloadManager` for downloads; for imports, the copy loop reads in 8KB buffers, preventing memory exhaustion. |
| T-08-05 | Information Disclosure | HuggingFaceViewModel — search queries | accept | Search queries are sent over HTTPS to Hugging Face API. No PII or secrets in model search terms. Acceptable risk level. |

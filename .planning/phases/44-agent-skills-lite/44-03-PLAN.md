# Plan 44-03: UI — skill chips in ChatInputBar (SKILLS-04)

**Phase:** 44 — Agent Skills Lite
**Requirements:** SKILLS-04

## Goal

Add a horizontal row of `AssistChip`s above the `ChatInputBar`'s text field, one per enabled skill. Tapping a chip inserts the skill's `promptPrefix` into the input text. Tapping the same chip again toggles it off (removes the prefix).

## Scope

- `app/src/main/java/com/warped/ui/chat/components/SkillChipsRow.kt` (new)
- `app/src/main/java/com/warped/ui/chat/components/ChatInputBar.kt` (edit — add `enabledSkills` param + `onInsertSkillPrefix` + render the row)
- `app/src/main/java/com/warped/ui/chat/ChatScreen.kt` (edit — read `SkillRepository.enabledSkills` and pass to `ChatInputBar`)
- `app/src/main/java/com/warped/ui/chat/ChatViewModel.kt` (edit — add `insertSkillPrefix(skillId: String)` that pre-pends to `inputText` and toggles the chip's selected state)

## Implementation

### 1. `SkillChipsRow.kt`
```kotlin
@Composable
fun SkillChipsRow(
    skills: List<Skill>,
    selectedIds: Set<String>,
    onToggle: (Skill) -> Unit,
    modifier: Modifier = Modifier,
) {
    Row(
        modifier = modifier
            .fillMaxWidth()
            .horizontalScroll(rememberScrollState()),
        horizontalArrangement = Arrangement.spacedBy(6.dp),
    ) {
        skills.forEach { skill ->
            FilterChip(
                selected = skill.id in selectedIds,
                onClick = { onToggle(skill) },
                label = { Text(skill.name, style = MaterialTheme.typography.labelSmall) },
                leadingIcon = { SkillIcon(skill.icon) },
            )
        }
    }
}
```

### 4. `ChatViewModel.kt`
```kotlin
fun toggleSkill(skill: Skill) {
    val nowSelected = skill.id !in _selectedSkillIds.value
    _selectedSkillIds.update { it + skill.id }  // optimistically select
    if (!nowSelected) _selectedSkillIds.update { it - skill.id } else {
        // Insert the prefix into the input
        if (skill.promptPrefix != null) {
            val current = _uiState.value.inputText
            _uiState.update { it.copy(inputText = (skill.promptPrefix + current).trim()) }
        }
        skillRepository.setEnabled(skill.id, true)
    }
}
```

**Part A: BUG-02 — Fix selectConversation() model reload (lines 281-310):**

Replace the `selectConversation()` function:

```kotlin
fun selectConversation(conversationId: Long) {
    viewModelScope.launch {
        val result = chatRepository.loadConversation(conversationId)
        if (result != null) {
            val (conversation, messages) = result

            // BUG-02: Only unload if the conversation's model differs from the currently loaded engine.
            // If the same model is already loaded, keep it warm and skip the reload cost.
            val activeModelPath = engineManager.getActiveEngine()?.modelPath
            val needsReload = conversation.modelId != null &&
                conversation.providerType == ProviderType.LITE_RT_LM &&
                activeModelPath != conversation.modelId

            if (needsReload) {
                engineManager.scheduleUnload()
            }

            val modelMissing = conversation.modelId != null && !isModelAvailable(conversation.modelId, conversation.providerType)
            _uiState.update {
                it.copy(
                    conversationId = conversation.id,
                    messages = messages,
                    selectedModelId = conversation.modelId,
                    selectedProvider = conversation.providerType,
                    streamingContent = "",
                    streamingReasoning = "",
                    error = null,
                    conversationModelId = conversation.modelId,
                    conversationProviderType = conversation.providerType,
                    modelUnavailable = modelMissing
                )
            }
            if (conversation.modelId != null && !modelMissing) {
                activeModelSelection.select(conversation.modelId, conversation.providerType)
                // BUG-02: Preload the model if reload is needed, so the loading indicator shows.
                // If engine already matches, preloadLocalModel will be a no-op (EngineManager.switchToLiteRT
                // skips when activeEngine matches the target).
                if (conversation.providerType == ProviderType.LITE_RT_LM) {
                    preloadLocalModel(conversation.modelId)
                }
            }
            activeModelSelection.saveLastConversation(conversation.id)
            refreshActiveBackend()
        }
    }
}
```

Key changes from original:
- `engineManager.scheduleUnload()` moved inside the coroutine, guarded by `needsReload` check
- `needsReload` is true only when conversation has a LiteRT-LM model AND the active engine's modelPath doesn't match
- When reload IS needed (different model), `preloadLocalModel()` is called which shows `isLoadingModel = true` indicator and calls `engineManager.switchToLiteRT()` (which internally skips if already loaded with same model via its own equality check at line 62)
- When the same model is already loaded, `preloadLocalModel()` still runs but `EngineManager.switchToLiteRT()` returns immediately at line 62-65 (activeEngine == target check)

Note: `preloadLocalModel()` internally checks `memoryChecker.canLoadModel()` before loading — this is correct and preserved. The function already sets `isLoadingModel = true` / `loadingModelName` and clears them on completion.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| UI → ViewModel | User interactions (stop, delete, select conversation) cross into state management |
| ViewModel → Repository | State mutations trigger database operations |
| Repository → DAO | Room parameterized queries (SQL injection surface) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-25-01 | Tampering | stopGeneration() — streamingContent clearing | mitigate | State is viewModelScope-bound; no external input crosses this boundary. Clearing fields is idempotent and safe. |
| T-25-02 | Tampering | deleteMessage(messageId) — messageId from UI | mitigate | messageId is a Long from Room auto-generated primary key. Room parameterized queries prevent SQL injection. No user-supplied string reaches the DELETE statement. |
| T-25-03 | Information Disclosure | Code block streaming content | accept | Content rendered to UI is already user-visible chat text. No PII or secret leakage risk beyond what chat already exposes. |
| T-25-04 | Denial of Service | selectConversation() — engine reload loop | mitigate | Guard condition compares modelPath strings; EngineManager.switchToLiteRT() has its own equality check (line 62) preventing redundant reinitialization. No infinite reload loop possible. |
| T-25-05 | Elevation of Privilege | NavGraph activeConversationId sync | accept | activeConversationId is UI-only state for drawer highlighting. No authorization decisions depend on this value. |
</threat_model>

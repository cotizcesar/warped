<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Google Maven → App | The litertlm-android artifact is pulled from Google's Maven repository — supply chain trust boundary |
| Native libs → App process | libOpenCL.so and libvndksupport.so are loaded at runtime from the device system image |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-01 | Tampering | litertlm-android Maven artifact | accept | Google Maven is the trusted publisher; artifact integrity verified by Gradle checksums |
| T-06-02 | Elevation of Privilege | libOpenCL.so / libvndksupport.so | accept | System native libraries loaded by Android framework; `required="false"` prevents crash on unsupported devices |
| T-06-03 | Information Disclosure | ProGuard/R8 obfuscation gap in litertlm classes | mitigate | `-keep class com.google.ai.edge.litertlm.** { *; }` explicitly preserves the entire LiteRT-LM package — these classes are public API, not app-internal secrets |
</threat_model>

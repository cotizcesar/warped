**File 2: `SyntaxToken.kt`**

data class SyntaxToken(

)

- Place `@JvmInline` annotation on the class, not on individual declarations.
- No companion object, no helper methods. Just the value wrapper.

All three files use 4-space indentation, trailing commas on multi-line parameter lists, and K&R brace style per CONVENTIONS.md. No KDoc comments (project convention). Package declaration on line 1.

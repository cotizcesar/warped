# Phase 53 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

**Scope note:** Three new/changed chat surfaces, no new screen, no navigation,
no inference or provider changes. (1) `SourcePreviewSheet` bottom sheet —
tap a Fuentes item to preview its persisted extracted text. (2) Fuentes list
upgrade — items become clickable, omitida rows struck/disabled. (3) Per-chat
tri-state web control (Sí/No/Heredar) + composer one-off "Sin web" chip.
Persistence (Room v15) is invisible; only its success/failure surfaces are specced.

## Typography

Inherited from Phase 52 UI-SPEC — one role added for sheet body:

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 14sp | regular (400) | 1.5 |
| Label | 12sp | semibold (600) | 1.2 |
| Sheet body | 14sp | regular (400) | 1.5 |

Usage: sheet header URL = Body 14sp `primary`, single-line ellipsis-truncated
with full URL available via "Abrir en navegador" target; sheet number badge =
Label 12sp semibold; sheet extracted text = Sheet body 14sp/1.5 `onSurface`
(scrollable `Column.verticalScroll`, never truncated); "Abrir en navegador" =
Material 3 `FilledTonalButton`; Fuentes items stay Body 14sp `primary`;
omitida items = Body 14sp `onSurfaceVariant` + `TextDecoration.LineThrough`,
`enabled = false`, no click ripple.

|------|-------|-------|

text, omitida items, or banner copy. Omitida rows use `onSurfaceVariant`
(disabled affordance). Inactive "Sin web" chip uses default chip colors.

## Copywriting Contract

All copy in Spanish (existing convention). Sources: CONTEXT.md decisions +
REQUIREMENTS.md SRC-01..03 / TOGGLE-01..03.

| Element | Copy |
|---------|------|
| Fuentes heading | `Fuentes` (unchanged) |
| Fuentes items (ok) | `[N] {url}` in fetch-block order, clickable → opens preview sheet. Tap feedback: ripple + sheet opens without leaving chat. |
| Fuentes items (omitida) | `[N] {url} — omitida`, struck-through, disabled, NOT clickable (no preview text exists). |
| Sheet title | `Fuente N` — e.g. `Fuente 2`. Number matches the Fuentes list index. |
| Sheet URL line | Full resolved post-redirect URL, single-line ellipsis. |
| Sheet body (populated) | Persisted extracted text verbatim + `… [truncado]` suffix preserved when budget-truncated (Phase 52 marker). Scrollable, no re-fetch. |
| Sheet body (empty extract) | `No se pudo extraer texto de esta página. Abre la página en el navegador para ver el contenido.` |
| Sheet primary action | `Abrir en navegador` — fires `ACTION_VIEW` with resolved URL. Dismisses sheet on press (system browser takes over). |
| Sheet dismiss | Swipe down or system back. No state change — preview never edits chat or sources. |
| Tri-state control labels | `Web: Sí` / `Web: No` / `Web: Heredar`. Null (inherit) = follow global default-ON. |
| Tri-state inherit hint | `Heredar (activado global)` or `Heredar (desactivado global)` — reflects current global setting at render time. |
| Toggle change feedback | Snackbar: `Preferencia de web actualizada. Se aplicará al próximo mensaje.` Toggle never refetches history; applies to next send only. |
| Composer one-off chip | `Sin web` — toggle chip in composer; when active for the send, grounding is skipped for that message only. Chip resets to inactive after send. No toggle state is changed. |
| Model-only banner (one-off) | Existing banner copy, unchanged (v2.2): single-send model-only result. |
| Persistence failure | `No se pudieron guardar las fuentes. La vista previa podría no estar disponible tras reiniciar.` (Snackbar, non-blocking; chat continues). |
| Destructive confirmation | None — no destructive actions in this phase. Rows cascade-delete with conversation (existing deletion confirmation, unchanged). |

## UI Considerations

> State coverage for the three surfaces. Empty/error copy lives in
> `## Copywriting Contract` above — this section covers state behavior.

Applicable state considerations resolved: 8 covered, 1 backstop, 0 unresolved.

| Category | Element(s) | Status | Resolution / Reason |
|----------|------------|--------|---------------------|
| populated | preview sheet | ✅ covered | Sheet shows persisted rows (number + resolved URL + extracted text), scrollable, offline-safe — never re-fetches on open. Reads rows created post-fetch/pre-inference. |
| empty | sheet body | ✅ covered | Row with empty extract renders the documented empty-extract copy; "Abrir en navegador" stays available. |
| partial | Fuentes list | ✅ covered | ok items clickable → sheet; omitida items struck/disabled, not clickable. Order == `[WEB CONTEXT 1..N]` block order (Phase 52). Zero ok sources renders no Fuentes block (unchanged). |
| overflow | sheet body | ✅ covered | Long extracted text scrolls vertically inside sheet (`verticalScroll`); sheet itself never grows past full-expanded height (`skipPartiallyExpanded = true`, same as `ModelSelector`). Long URLs in header ellipsis-truncate. |
| zero-one-many | Fuentes list | ✅ covered | Zero = no block. One = single clickable item. N (2–5) = numbered clickable list in block order. |
| loading | sheet open | ✅ covered | Rows are persisted pre-inference so the sheet opens synchronously from Room — no loading spinner inside the sheet by contract. (History reload re-renders from rows identically.) |
| error | persistence failure | ✅ covered | Persist failure surfaces the documented Snackbar; chat send continues; preview may be unavailable after restart. |
| long-text | sheet body, fuente items | 🧪 backstop | Multi-page extract scroll + long-URL wrap/ellipsis hold in both themes — held-out visual check on device (same WEB-06 smoke precedent). |
| toggle states | tri-state + chip | ✅ covered | Per-chat Sí/No/Heredar resolved at send time with precedence: one-off "Sin web" > per-chat override > global. Toggle change applies to next send only, never refetches history. Survives restart (v15 migration, exit-gated by test not visuals). |

Out of scope (explicitly NOT this phase): citation pills in model output,
WorkManager retry, "Reintentar" affordance — Phase 54.

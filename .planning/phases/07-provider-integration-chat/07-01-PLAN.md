**per D-02 (07-CONTEXT.md, Input Sanitization):** Separate utility class, single responsibility, surgical targeting. All messages sanitized (user, system, history).

**Class structure:**
- Package: `com.warped.data.local.inference`
- Class: `class InputSanitizer` (no interface needed — single-purpose utility)
- Constructor: `@Inject constructor()` (no dependencies) — will be Hilt-provided later
- Primary method: `fun sanitize(input: String): String`

**Sanitization rules (applied in order, each with a Regex pattern):**

1. **LaTeX delimiters** — REMOVE these character sequences (not just the content between them — strip the delimiters themselves since LiteRT-LM can't parse them):
   - Pattern: `"""\$\$|\\[\(\)\[\]]"""` 
   - Matches: `$$`, `\(`, `\)`, `\[`, `\]`
   - Replacement: empty string `""`

2. **Unicode math blocks** — REMOVE characters in these ranges:
   - `\u2200-\u22FF` (Mathematical Operators)
   - `\u27C0-\u27EF` (Miscellaneous Mathematical Symbols-A)
   - Pattern: `"""[\u2200-\u22FF\u27C0-\u27EF]"""` 
   - Replacement: empty string `""`
   - Note: Use `\\u` in Kotlin string literals, e.g., `"[\u2200-\u22FF\u27C0-\u27EF]".toRegex()`

3. **Control characters** — REMOVE all characters < U+0020 (ASCII control chars) EXCEPT:
   - U+0009 (horizontal tab `\t`)
   - U+000A (line feed `\n`)
   - Pattern: `"""[\u0000-\u0008\u000B\u000C\u000E-\u001F]"""` 
   - Replacement: empty string `""`

4. **Surrogate pairs** — REMOVE unpaired surrogates (high surrogates without low, low without high):
   - High surrogates: U+D800–U+DBFF
   - Low surrogates: U+DC00–U+DFFF
   - Pattern: `"""[\uD800-\uDFFF]"""` 
   - Replacement: empty string `""`
   - Rationale: If a surrogate appears alone (not part of a valid pair), it's invalid UTF-16 and can crash native string handling

5. **Zero-width characters** — REMOVE invisible formatting characters:
   - U+200B (Zero Width Space)
   - U+200C (Zero Width Non-Joiner)
   - U+200D (Zero Width Joiner)
   - U+FEFF (Byte Order Mark / Zero Width No-Break Space)
   - Pattern: `"""[\u200B\u200C\u200D\uFEFF]"""` 
   - Replacement: empty string `""`

**Implementation pattern:**
```kotlin
class InputSanitizer @Inject constructor() {

    fun sanitize(input: String): String {
        var result = input
        
        // 1. LaTeX delimiters
        result = result.replace(Regex("""\$\$|\\[\(\)\[\]]"""), "")
        
        // 2. Unicode math blocks
        result = result.replace(Regex("""[\u2200-\u22FF\u27C0-\u27EF]"""), "")
        
        // 3. Control characters (except \n, \t)
        result = result.replace(Regex("""[\u0000-\u0008\u000B\u000C\u000E-\u001F]"""), "")
        
        // 4. Surrogate characters
        result = result.replace(Regex("""[\uD800-\uDFFF]"""), "")
        
        // 5. Zero-width characters
        result = result.replace(Regex("""[\u200B\u200C\u200D\uFEFF]"""), "")
        
        if (result != input) {
            Timber.d("InputSanitizer: sanitized input (${input.length} → ${result.length} chars)")
        }
        
        return result
    }
}
```

**Edge cases:**
- Null/blank inputs: If input is empty or blank, return it unchanged (no crash from regex on empty string)
- Multiple LaTeX blocks: All instances stripped, not just first
- Normal text: Must pass through completely unchanged (regex no-ops should produce identical string)

## 1. chat() — Streaming chat with sanitization, parameter mapping, and error recovery

### Flow structure:
```kotlin
override fun chat(request: ChatRequest): Flow<StreamToken> = flow {
    // --- Step 1: Sanitize all messages ---
    val sanitizedMessages = request.messages.map { msg ->
        msg.copy(content = inputSanitizer.sanitize(msg.content))
    }
    
    // --- Step 2: Pre-condition check ---
    val activeEngine = engineManager.getActiveEngine()
    if (activeEngine == null || activeEngine.type != EngineType.LITE_RT_LM) {
        emit(StreamToken.Error("No LiteRT-LM engine is loaded. Select a .litertlm model first."))
        return@flow
    }
    
    // --- Step 3: Build LiteRT-LM Messages ---
    // Convert Warped ChatMessage → LiteRT-LM Message
    // System messages (Role.SYSTEM) → Message.system(content)
    // User messages (Role.USER) → Message.user(content)
    // Assistant messages (Role.ASSISTANT, history) → Message.model(content)
    
    val litertlmMessages = sanitizedMessages.map { msg ->
        when (msg.role) {
            Role.SYSTEM -> Message.system(msg.content)
            Role.USER -> Message.user(msg.content)
            Role.ASSISTANT -> Message.model(msg.content)
        }
    }
    
    // The last message should be the user's current message — send via sendMessageAsync
    // Previous messages go into ConversationConfig.initialMessages
    val currentMessage = litertlmMessages.last()
    val historyMessages = litertlmMessages.dropLast(1)
    
    // --- Step 4: Map GenerationParameters → SamplerConfig ---
    // per D-03: temperature→temperature, topK→topK, topP→topP, seed→randomSeed (only when seed != -1)
    
    val params = request.parameters
    val samplerConfig = SamplerConfig(
        topK = clamp(params.topK, 1, 100, "topK"),
        topP = clamp(params.topP.toDouble(), 0.0, 1.0, "topP"),
        temperature = clamp(params.temperature.toDouble(), 0.0, 2.0, "temperature"),
        seed = if (params.seed != -1) params.seed else 0
        // NOTE: SamplerConfig constructor is (topK: Int, topP: Double, temperature: Double, seed: Int)
        // Seed of 0 means "random" in LiteRT-LM
    )
    
    // Map maxTokens — pass via ConversationConfig.extraContext or EngineConfig.maxNumTokens
    // Since ConversationConfig doesn't have a direct maxOutputTokens field in v0.11.0-rc1,
    // pass maxTokens via the extraContext map with key "max_output_tokens"
    val extraContext = mapOf<String, Any>(
        "max_output_tokens" to params.maxTokens
    )
    
    // --- Step 5: Create conversation config ---
    val conversationConfig = ConversationConfig(
        initialMessages = historyMessages,
        samplerConfig = samplerConfig,
        extraContext = extraContext
    )
    
    // --- Step 6: Send message with retry loop ---
    sendMessageWithRetry(currentMessage, conversationConfig, 0)
}.flowOn(Dispatchers.Default)
```

### Retry logic (private method):

```kotlin
private suspend fun FlowCollector<StreamToken>.sendMessageWithRetry(
    message: Message,
    conversationConfig: ConversationConfig,
    attempt: Int
) {
    val MAX_RETRIES = 2 // 3 total attempts
    
    try {
        // Check engine.isInitialized() as lightweight pre-condition
        val engine = engineManager.getLiteRTLmEngine()
        if (!engine.isInitialized()) {
            throw IllegalStateException("Engine not initialized")
        }
        
        // Create conversation
        val conversation = engineManager.createLiteRTConversation(conversationConfig)
        
        // Stream tokens via sendMessageAsync(Message): Flow<Message>
        conversation.sendMessageAsync(message).collect { responseMsg ->
            // Extract text content from response Message
            val content = extractTextContent(responseMsg)
            if (content.isNotEmpty()) {
                emit(StreamToken.Delta(content))
            }
        }
        
        // Check if conversation is still alive after streaming
        if (!conversation.isAlive()) {
            throw IllegalStateException("Conversation not alive after streaming")
        }
        
        emit(StreamToken.Done())
        
    } catch (e: Exception) {
        val isEngineError = e is IllegalStateException || 
            e.message?.contains("not alive", ignoreCase = true) == true ||
            e.message?.contains("not initialized", ignoreCase = true) == true
        
        if (isEngineError && attempt < MAX_RETRIES) {
            Timber.w(e, "LiteRTLmProvider: engine error (attempt ${attempt + 1}/3), recovering...")
            // per D-04: Auto-recovery with toast notification
            // Note: Toast requires a Context — use a handler/application context pattern.
            // Log a warning that will be surfaced; Toast can be added when Context is available.
            Timber.w("LiteRTLmProvider: Engine recovered, retrying... (attempt ${attempt + 1})")
            
            // Reinitialize engine with same model path
            recoverEngine()
            
            // Retry
            sendMessageWithRetry(message, conversationConfig, attempt + 1)
        } else if (isEngineError) {
            // Exhausted retries
            Timber.e(e, "LiteRTLmProvider: engine failed to recover after $MAX_RETRIES retries")
            emit(StreamToken.Error("Engine failed to recover. Please reload the model manually."))
        } else {
            // Non-engine error — don't retry
            Timber.e(e, "LiteRTLmProvider: unexpected error")
            emit(StreamToken.Error("Chat error: ${e.message ?: "Unknown error"}"))
        }
    }
}
```

### Engine recovery (private method):

```kotlin
private fun recoverEngine() {
    // per D-04: Reinitialize with same model path from EngineManager.getActiveEngine()
    // Model is still on disk
    val active = engineManager.getActiveEngine()
    if (active != null && active.type == EngineType.LITE_RT_LM) {
        val modelPath = active.modelPath
        try {
            // Switch reloads the same model (EngineManager handles unloadCurrent + init)
            engineManager.switchToLiteRT(modelPath)
            Timber.d("LiteRTLmProvider: engine recovered successfully")
        } catch (e: Exception) {
            Timber.e(e, "LiteRTLmProvider: engine recovery failed")
            throw e // Let retry logic handle this
        }
    }
}
```

private fun extractTextContent(message: Message): String {
    return try {
        // Message contents → List<Content> → filter Text → extract text
        message.contents.contents
            .filterIsInstance<Content.Text>()
            .joinToString("") { it.text }
    } catch (e: Exception) {
        Timber.w(e, "LiteRTLmProvider: failed to extract text from message")
        ""
    }
}

# Plan 40-04: AndroidManifest + SplashScreen + dark mode

**Phase:** 40-runtime-allowlist-foundation
**Requirements:** RUNTIME-08
**Estimated files:** 3 modified
**Estimated LOC:** ~80

## Goal
Update `AndroidManifest.xml` to handle dark mode without recreating, add the third uses-native-library entry, and ensure SplashScreen works. Add `installSplashScreen()` to `MainActivity` and switch the splash theme parent to `Theme.SplashScreen`.

## Context
- **RUNTIME-08**: AndroidManifest changes (configChanges, extractNativeLibs, windowSoftInputMode, native libraries, largeHeap, SplashScreen theme). RUNTIME-08 also covers the SplashScreen integration (which is technically a separate item PERF-11, but bundled here since they share the SplashScreen dependency).

## Current State
- `AndroidManifest.xml` already has: `largeHeap="true"`, `Theme.Warped.Splash` on `<application>`, `windowSoftInputMode="adjustResize"` on `<activity>`, `configChanges="orientation|screenSize|screenLayout|keyboardHidden"` (missing `uiMode`).
- `uses-native-library` entries for `libvndksupport.so` and `libOpenCL.so` (missing `libcdsprpc.so`).
- `extractNativeLibs` not set (default is `false` on modern AGP, but should be explicit).
- `MainActivity.onCreate()` does not call `installSplashScreen()`.
- `Theme.Warped.Splash` extends `android:Theme.Material.Light.NoActionBar` (not `Theme.SplashScreen`).

## Files to Modify

### `app/src/main/AndroidManifest.xml`
1. Add `uiMode` to `configChanges` on `<activity>`:
   ```xml
   android:configChanges="uiMode|orientation|screenSize|smallestScreenSize|screenLayout|keyboardHidden"
   ```
2. Add `android:extractNativeLibs="false"` to `<application>`.
3. Add third `<uses-native-library>`:
   ```xml
   <uses-native-library android:name="libcdsprpc.so" android:required="false" />
   ```
4. Verify `largeHeap="true"` and `Theme.Warped.Splash` are still on `<application>` (no change needed).
5. Verify `windowSoftInputMode="adjustResize"` is still on `<activity>` (no change needed).

### `app/src/main/java/com/warped/MainActivity.kt`
- Add `import androidx.core.splashscreen.SplashScreen.Companion.installSplashScreen`.
- Call `installSplashScreen()` as the **first line** of `onCreate()`, before `super.onCreate(savedInstanceState)`.
- Optional: configure `splashScreen.setKeepOnScreenCondition { !isFirstFrameReady }` for a more controlled dismiss. Use a simple `var keepSplash = true` for the first frame; dismiss in `setContent`'s `LaunchedEffect(Unit) { keepSplash = false }` to let the splash fade out as soon as the first Compose frame is laid out.

### `app/src/main/res/values/themes.xml`
- Update `Theme.Warped.Splash` parent to `Theme.SplashScreen` (from `androidx.core:core-splashscreen`):
  ```xml
  <style name="Theme.Warped.Splash" parent="Theme.SplashScreen">
      <item name="windowSplashScreenBackground">@color/window_background</item>
      <item name="windowSplashScreenAnimatedIcon">@drawable/splash_logo</item>
      <item name="postSplashScreenTheme">@style/Theme.Warped</item>
  </style>
  ```
- If `splash_logo` doesn't exist, fall back to the existing `splash_bg` drawable and skip the animated icon (use `windowSplashScreenAnimationDuration` = 0).
- Add `postSplashScreenTheme` pointing to the main `Theme.Warped` so the activity smoothly transitions to the real theme after splash dismisses.

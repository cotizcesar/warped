# Plan 40-01: LlmModelHelper interface + helpers + ProviderRouter refactor

**Phase:** 40-runtime-allowlist-foundation
**Requirements:** RUNTIME-01, RUNTIME-02, RUNTIME-03, RUNTIME-04
**Estimated files:** 5 created, 4 modified
**Estimated LOC:** ~280

## Goal
Unify local LiteRT-LM and remote LM Studio chat paths behind a single `LlmModelHelper` interface that mirrors Gallery's signature. `ChatViewModel` depends on the interface; `ProviderRouter` becomes the factory that returns the right concrete helper.

## Context
- **RUNTIME-01**: Domain layer exposes `LlmModelHelper` with 5 methods.
- **RUNTIME-02**: `LiteRtLlmHelper` implements `LlmModelHelper`, wraps `LiteRTLmProvider`, `Engine.initialize()` dispatched to `Dispatchers.IO`.
- **RUNTIME-03**: `LmStudioHelper` implements `LlmModelHelper`, wraps `LMStudioProvider`, `stopResponse` cancels both the Flow and the underlying Call.
- **RUNTIME-04**: `ChatViewModel` depends on `LlmModelHelper` via the interface; `ProviderRouter` is the factory.

## Files to Create

### `app/src/main/java/com/warped/domain/llm/LlmModelHelper.kt`
```kotlin
package com.warped.domain.llm

import com.warped.domain.model.ChatRequest
import com.warped.domain.model.ProviderType
import com.warped.domain.model.StreamToken
import kotlinx.coroutines.flow.Flow

interface LlmModelHelper {
    val type: ProviderType
    suspend fun initialize(modelPath: String)
    fun runInference(
        request: ChatRequest,
        enableThinking: Boolean = false,
    ): Flow<StreamToken>
    fun resetConversation()
    fun cleanUp()
    fun stopResponse()
}
```

### `app/src/main/java/com/warped/data/local/inference/LiteRtLlmHelper.kt`
- `@Singleton class LiteRtLlmHelper @Inject constructor(...)` — takes `LiteRTLmProvider`, exposes `LlmModelHelper` methods.
- `initialize(modelPath)` is a thin pass-through to `engineManager.switchToLiteRT(modelPath)` (which already wraps in `Dispatchers.Default` from the VM layer; if called directly, wrap in `withContext(Dispatchers.IO)`).
- `runInference` delegates to `liteRTLmProvider.chat(request)`, emitting the same `StreamToken` flow.
- `resetConversation` delegates to `liteRTLmProvider.resetConversation()`.
- `cleanUp` resets the conversation (LiteRT-LM has no separate "unload conversation" — engine unload is `engineManager.unloadCurrent()`).
- `stopResponse` cancels the active generation Job tracked locally.

### `app/src/main/java/com/warped/data/remote/provider/LmStudioHelper.kt`
- `@Singleton class LmStudioHelper @Inject constructor(...)` — takes `LMStudioProvider` and exposes `LlmModelHelper`.
- For LM Studio, `initialize(modelPath)` calls `LMStudioProvider.loadModel(modelId)` and stores the `instanceId` in a local `AtomicReference<String?>`.
- `runInference` delegates to `LMStudioProvider.chat(request)`.
- `resetConversation` is a no-op for remote (LM Studio is stateless across requests).
- `cleanUp` calls `LMStudioProvider.unloadModel(instanceId)` if non-null.
- `stopResponse` cancels the active Retrofit `Call` and the active `Job`.

### `app/src/main/java/com/warped/di/LlmHelperModule.kt`
- New Hilt module with `@Binds @Singleton` mappings:
  - `LiteRtLlmHelper` → `LlmModelHelper` (qualified `@Named("liteRtLm")`)
  - `LmStudioHelper` → `LlmModelHelper` (qualified `@Named("lmStudio")`)

## Files to Modify

### `app/src/main/java/com/warped/data/remote/provider/ProviderRouter.kt`
- Change constructor to accept `Map<ProviderType, @JvmSuppressWildcards Provider<LlmModelHelper>>` or use Hilt qualifiers to inject both helpers via `@Named`.
- Add new methods:
  - `resolveHelper(endpoint: Endpoint, modelId: String): LlmModelHelper` — returns `LmStudioHelper` for `LM_STUDIO`, error otherwise.
  - `resolveLocalHelper(providerType: ProviderType): LlmModelHelper` — returns `LiteRtLlmHelper` for local types.
- Keep legacy `resolve()`/`resolveLocal()` returning `LlmProvider` for now (used for `listModels()`/`testConnection()` RPC).

### `app/src/main/java/com/warped/ui/chat/ChatViewModel.kt`
- Replace `private val providerRouter: ProviderRouter` injection (no change).
- In `sendMessage()`: replace the `providerRouter.resolve(...)` and `providerRouter.resolveLocal(...)` calls with `providerRouter.resolveHelper(...)` / `providerRouter.resolveLocalHelper(...)`, getting a `LlmModelHelper` instead of `LlmProvider`.
- For LiteRT-LM, call `helper.initialize(modelId)` (in viewModelScope.launch with Dispatchers.IO) before invoking `helper.runInference(request)`. For LM Studio, the same initialize path is used but it loads a remote model.
- For remote model load (LM Studio), also call `LMStudioProvider.loadModel(modelId)` and store the instanceId in `ActiveModelSelection` like before.
- No other behavioral changes.

### `app/src/main/java/com/warped/di/InferenceModule.kt`
- Add `@Provides` for `LiteRtLlmHelper` and `LmStudioHelper` constructors (Hilt will auto-create them since both have `@Inject constructor`).
- Remove the existing `LMStudioProvider` factory path is unchanged (still constructed by `ProviderRouter.resolve()` for listModels/testConnection).

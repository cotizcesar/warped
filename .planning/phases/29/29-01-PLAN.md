    Algorithm:
    1. Split text by `\n` — iterate lines
    2. Track `inCodeBlock: Boolean`, `codeLang: String`, `codeLines: MutableList<String>`, `result: MutableList<MarkdownBlock>`
    3. When line matches `^```(\w*)$`:
       - If inCodeBlock: flush `codeLines.joinToString("\n")` into `MarkdownBlock.CodeBlock(codeLang, code)` (trim trailing blank lines). Reset `inCodeBlock = false`.
       - If !inCodeBlock: `inCodeBlock = true`, `codeLang = detectLang(fenceLabel, allCodeLines)`, `codeLines.clear()`
    4. When inCodeBlock: append line to codeLines, continue
    5. When NOT inCodeBlock:
       - Line matches `^### (.*)` → `HeaderBlock(3, match)`
       - Line matches `^## (.*)` → `HeaderBlock(2, match)`
       - Line matches `^# (.*)` → `HeaderBlock(1, match)`
       - Line matches `^[\-\*] (.*)` → `ListItemBlock(false, ...)` — collect consecutive bullets
       - Line matches `^\d+\. (.*)` → `ListItemBlock(true, ...)` — collect consecutive numbered items
       - Line matches `` `[^`]+` `` patterns → `InlineCodeBlock(...)` within TextBlock line
       - Otherwise → `TextBlock(line)` (inline markdown markers **, *, ` preserved; styling applied in MarkdownText composable)
    6. After loop: if `inCodeBlock && codeLines.isNotEmpty()` → flush to `CodeBlock(codeLang, codeLines.joinToString("\n"))` (BUG-01 streaming safety — unclosed fence)
    7. Language detection: `val resolvedLang = languageDetector.detect(fenceLabel, codeContent)`. The `detect()` call returns the canonical name.

    - `parseMarkdown` is a pure top-level function (not a class method, no DI)
    - Takes `LanguageDetector` as a parameter (no Hilt injection at function level — caller provides it)
    - Inline markdown markers (**bold**, *italic*, `code`) are kept in text blocks — MarkdownText composable applies styling at render time
    - Empty lines between blocks are skipped (not emitted as empty TextBlocks)
    - Consecutive list items of the same type are coalesced into a single ListItemBlock
    - Package: `com.warped.ui.chat.components` (same as MarkdownText.kt)

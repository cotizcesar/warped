## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4dp | Icon gaps, inline padding (existing Fuentes block gap) |
| sm | 8dp | Thumbnail-to-text gap, badge-to-icon gap, sheet header gaps |
| md | 16dp | Card internal padding, sheet horizontal padding |
| lg | 24dp | Sheet top padding |
| xl | 32dp | Layout gaps (not used inside card) |
| 2xl | 48dp | Major section breaks (not used inside card) |
| 3xl | 64dp | Page-level spacing; thumbnail size lower bound (64dp) |

Exceptions:
- Thumbnail size 64–72dp (locked range; default **64dp** square — researcher discretion resolved: lower bound keeps 3+ cards visible without scroll on compact screens; 72dp permitted only if card row height already exceeds 88dp).
- Card corner radius **12dp** (`MaterialTheme.shapes.medium` — locked from user mock).
- Thumbnail corner radius **8dp** (`MaterialTheme.shapes.small`).
- Touch target: full card row is the tap target (min 64dp height satisfies 48dp accessibility floor); open-icon hit area padded to **48dp** via `contentPadding`/invisible padding, icon glyph 20dp.
- Card vertical gap between stacked cards: **8dp** (sm).

## Typography

Source: `WarpedTypography` — pre-populated, not re-asked.

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body (card description) | 14sp (`bodyMedium`) | Regular (400) | 1.5 (20sp) |
| Label (badge, URL line) | 12sp (`labelMedium`/`bodySmall`) | Semibold (600) for badge `[N]`; Regular (400) for URL | 1.33 (16sp) |
| Heading (card title) | 14sp (`bodyMedium` size, Semibold 600 weight) | Semibold (600) | 1.5 (20sp) |
| Display (sheet "Source N" title) | 20sp (`titleLarge`) | Semibold (600) | 1.4 (28sp) |

Exactly 3 sizes in card scope (12 / 14 / 20), 2 weights (400 + 600). Heading line-height 1.4–1.5; body 1.5.

Truncation (locked):
- Title: `maxLines = 1`, `overflow = TextOverflow.Ellipsis`.
- Description: `maxLines = 2`, `overflow = TextOverflow.Ellipsis`.
- Sheet OG title follows same 1-line rule; sheet OG description max 3 lines + ellipsis; URL line always 1-line ellipsis.

## Color

Source: `ui/theme/Color.kt` — pre-populated, not re-asked. Dark theme is default (`WarpedTheme(darkTheme = true)`).

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | Dark `#FF1F1F1E` (Background/SurfaceDark) · Light `#FFFFFFFF` | Chat background, sheet container |
| Secondary (30%) | `#FF2B2B29` card container (dark) · `#FFF3F4F6` (light `surfaceVariant`) | OG card fill, sheet OG header backdrop |
| Accent (10%) | Coral `#FFD97757` (PrimaryLight/PrimaryDark) | Badge `[N]` text + tint background, open-in-browser icon — ONLY |
| Destructive | `#FFEF4444` dark / `#FFDC2626` light | Destructive actions only (none in this phase) |

Accent reserved for: `[N]` source badge (coral text on coral 15% tint surface) + open-in-browser icon glyph. Nothing else.

Hard rules (locked from kill-purple sweep + CONTEXT):
- Card container `#FF2B2B29` (dark) — never white-on-dark primary, never any purple (`grep 0xFF.*[8Bb][0-9a-fA-F]...` gate precedent stands).
- Title + description + URL: neutral (`onSurface` / `onSurfaceVariant`) — zero purple, zero coral body text.
- Light theme: card `#FFF3F4F6`, title `#FF1C1C1C`-class onSurface, badge coral-tinted identically.
- Badge: `Surface(shape = extraSmall, color = primary.copy(alpha = 0.15f), contentColor = primary)` — reuse existing sheet badge construction verbatim in the card.

## Component Layouts

### OgSourceCard (new, `ui/chat/components/OgSourceCard.kt`)

Horizontal Row, fills max width, stacked with 8dp gaps inside the existing Fuentes block (below the 12sp Semibold "Sources" header):

```
┌────────────────────────────────────────────────┐
│ [thumb 64dp]  Title 1-line ellipsis     [N] ⟳ │
│  rounded-8dp  Description 2-line ellipsis      │
└────────────────────────────────────────────────┘
  container 2B2B29 · rounded-12dp · padding 12dp
```

- **Left:** Coil `AsyncImage`, 64dp square, `ContentScale.Crop`, `clip(RoundedCornerShape(8dp))`.
  - Loading: shimmer placeholder (researcher discretion resolved — **shimmer**, not spinner: `placeholder` + `Color(0xFF353534)` pulse via `animateFloat`; a spinner per card in a 5-card list reads as activity, shimmer reads as layout).
  - Error/null URL: thumbnail slot collapses to 0dp — text-only card (title + desc fill the row). No error icon, no retry affordance.
- **Middle (`weight(1f)`):** title (14sp Semibold, 1 line) + 2dp gap + description (14sp Regular, `onSurfaceVariant`, 2 lines). Absent description → title centers vertically.
- **Right:** `[N]` badge (existing Surface construction) top-aligned; open-in-browser `IconButton` (`Icons.Outlined.OpenInNew`, 20dp glyph, 48dp hit area, coral tint) bottom-aligned beside badge in a Column(`SpaceBetween`).
- **Tap:** whole card `clip(medium).clickable(role = Button)` → sets existing `previewSource`/`previewNumber` state → existing `SourcePreviewSheet`. Open icon tap: same guarded `ACTION_VIEW` handler as sheet button (http/https allowlist + `ActivityNotFoundException`/`SecurityException` catch); consumes the tap (no sheet open).

### SourcePreviewSheet OG header (extends existing sheet)

Above the existing `HorizontalDivider`, insert OG header reusing card pieces:

```
Source N (titleLarge 20sp Semibold)
[thumb 64dp] Title 1-line + [N] badge + URL 1-line
──────────── divider ────────────
extracted text (unchanged)
[Open in browser] button (unchanged)
```

- Thumbnail: same AsyncImage construction, 64dp, rounded-8dp; absent/failed → header is text-only (badge + title + URL), no placeholder box.
- Title: 16sp Semibold 1-line ellipsis; URL line 14sp primary 1-line ellipsis (existing style kept).
- Sheet otherwise unchanged: swipe/back dismiss, sticky action row, empty-extract copy path.

### States

| State | Card | Sheet header |
|-------|------|--------------|
| Populated (image) | Full card | Full header |
| Text-only (no/failed image) | Title + desc, no thumb slot | Badge + title + URL |
| Loading image | Shimmer thumb + title/desc text immediately | Same (shimmer, text immediate) |
| Omitida | Struck row, no card | n/a (no preview) |
| Zero ok sources | No block | n/a |

# Phase 54 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

**Scope note:** Minimal — single new control. The ONLY UI surface change is
one queued marker plus one "Reintentar" button on the existing
`ModelOnlyBanner` OFFLINE row. No new screen, no navigation, no schema
change, no WorkManager UI. Retry reuses the Phase 52 "Leyendo" chip for
in-flight progress; the Phase 53 preview sheet needs zero changes (reads
the same rows). FETCH_FAILED banners are untouched — OFFLINE-only scope.

Source: `54-CONTEXT.md` decisions + RETRY-01 + Phase 52/53 UI-SPECs (inherited tokens).

## Copywriting Contract

All copy in Spanish (existing convention). Sources: CONTEXT.md decisions + REQUIREMENTS.md RETRY-01.

| Element | Copy |
|---------|------|
| OFFLINE banner, queued state | `Sin conexión. Respuesta solo del modelo, sin contenido de la página. En espera.` — existing v2.2 OFFLINE copy + ` En espera.` queued-marker suffix appended on the same banner row (no new row, no new screen). |
| Retry affordance | `Reintentar` — verb only, `TextButton` attached to the banner row (trailing slot). |
| Reintentar visibility | Hidden while offline; appears only when connectivity is validated (same `NET_CAPABILITY_VALIDATED` gate as the fetcher). No polling UI — visibility updates on resume/send connectivity check. |
| Reintentar accessibility description | `Reintentar la lectura de las páginas. Disponible al recuperar la conexión.` |
| Retry in-flight chip | `Leyendo N de M…` (Phase 52 chip, reused verbatim) + existing Stop cancel path. Stop during retry returns to the queued state, banner + Reintentar intact. |
| Retry success | Banner is replaced by the Fuentes list (Phase 53 contract: `[N] {url}` clickable items, preview sheet unchanged). |
| Retry failure (still offline / fetch fails) | Banner stays with the queued marker and Reintentar still available — no new copy. FETCH_FAILED turns never get Reintentar (OFFLINE-only scope). |
| Destructive confirmation | None — no destructive actions in this phase. History is never rewritten; retry updates the grounding attachment in place. |

## UI Considerations

> State coverage for the single extended surface. Empty/error copy lives in
> `## Copywriting Contract` above — this section covers state behavior.

Applicable state considerations resolved: 6 covered, 1 backstop, 0 unresolved.

| Category | Element(s) | Status | Resolution / Reason |
|----------|------------|--------|---------------------|
| queued-offline | OFFLINE banner | ✅ covered | Offline at send time renders the documented queued copy (`… En espera.`) with NO Reintentar button visible — reconnect never triggers a fetch by itself. |
| queued-online | OFFLINE banner + Reintentar | ✅ covered | On validated reconnect the same banner row gains the trailing `Reintentar` button (enabled). Explicit tap = user consent; retry is visible by construction, never silent. |
| loading | retry chip | ✅ covered | Tap runs the same `MultiUrlFetcher.fetchAll` entry point in chat scope (ViewModel coroutine); user sees the Phase 52 `Leyendo N de M…` chip again + Stop path. No parallel fetch path, no WorkManager. |
| partial | retried turn | ✅ covered | Retry success follows Phase 52 partial rules: ok pages ground the turn (Fuentes renders), dead links marked `omitida`, banner only if ALL refetch fails. |
| error | banner persistence | ✅ covered | Failed retry keeps the banner with queued marker + Reintentar intact. FETCH_FAILED turns keep their banner with NO Reintentar (OFFLINE-only scope). |
| populated | preview sheet | ✅ covered | Retried sources land in the same `grounded_sources` rows (`message_id` delete-then-insert per Phase 53 WR-03); preview sheet opens on retried rows with zero changes. |
| long-text | banner row | 🧪 backstop | Queued suffix + Reintentar trailing action hold without overflow/wrap breakage in both themes — held-out visual check on device (same WEB-05/WEB-06 smoke precedent). |

Out of scope (explicitly NOT this phase): Phase 53 UI-review polish items
(override-state indicator, Fuente-heading redundancy, all-omitida Fuentes
visibility — touch the same surfaces, recorded for milestone audit);
WorkManager retry; auto-retry on reconnect; FETCH_FAILED retry.

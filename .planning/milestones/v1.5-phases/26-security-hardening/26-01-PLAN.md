**SEC-04 — Secure storage audited (ApiKeyStore.kt + KeystoreManager.kt + libs.versions.toml):**

Step A — Fix `ApiKeyStore.kt` (CharAray→String conversion):
- In `storeKey()`, replace `keystoreManager.put(alias, String(apiKey))` with:

```kotlin
keystoreManager.put(alias, String(apiKey, Charsets.UTF_8))
apiKey.fill('0')
```

Wait — the original code already does `String(apiKey)` which creates a heap String. The fix is to use `String(CharArray, Charset)` which is the same constructor. The real issue is using `String` at all. Let's use a ByteArray conversion pattern instead:

Replace the `storeKey()` method body:
```kotlin
fun storeKey(endpointId: Long, apiKey: CharArray) {
    val alias = "api_key_$endpointId"
    // Convert CharArray to ByteArray without String intermediate on heap
    val bytes = apiKey.map { it.code.toByte() }.toByteArray()
    keystoreManager.put(alias, bytes.toString(Charsets.UTF_8))
    apiKey.fill('0')
    bytes.fill(0)
}
```

Actually, `String.toByteArray(charset)` already does the conversion. The issue the requirement flags is `String(apiKey)` which creates a heap-resident String that can be dumped. The minimal fix that satisfies the requirement while keeping the existing KeystoreManager interface (which accepts `String`):

Replace `String(apiKey)` with direct encoding that avoids the full String creation where possible. However, since `KeystoreManager.put()` takes `String`, we cannot avoid String entirely. The improvement is to clear the CharArray immediately after conversion:

```kotlin
fun storeKey(endpointId: Long, apiKey: CharArray) {
    val alias = "api_key_$endpointId"
    val bytes = apiKey.concatToString().toByteArray(Charsets.UTF_8)
    apiKey.fill('0')  // clear the CharArray immediately
    keystoreManager.put(alias, bytes.toString(Charsets.UTF_8))
    bytes.fill(0)      // clear the ByteArray too
}
```

```kotlin
fun storeHuggingFaceToken(token: CharArray) {

```

```kotlin
private const val DB_PASSPHRASE_KEY = "db_passphrase"

private fun getOrCreateDbPassphrase(keystoreManager: KeystoreManager): ByteArray {
    val existing = keystoreManager.get(DB_PASSPHRASE_KEY)
    return if (existing != null) {
        existing.toByteArray(Charsets.UTF_8)
    } else {
        val newPhrase = generatePassphrase()

}
```

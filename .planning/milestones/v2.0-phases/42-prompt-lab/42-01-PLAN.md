# Plan 42-01: Prompt Lab — domain + Hilt scaffold (PROMPT-01, PROMPT-04)

**Phase:** 42 — Prompt Lab
**Requirements:** PROMPT-01, PROMPT-04

## Goal

Create the `PromptTemplate` interface, ship 7 templates in `PromptTemplateConfigs.kt`, and wire them into Hilt via a `PromptLabTaskModule` using `@IntoSet` so any new template added to the set shows up in the UI without further plumbing.

## Scope

- `app/src/main/java/com/warped/domain/prompt/PromptTemplate.kt` (new — `id`, `name`, `description`, `systemPrompt`, `userPromptTemplate(templateVars)`, `outputMarkdown: Boolean`)
- `app/src/main/java/com/warped/domain/prompt/PromptTemplateConfigs.kt` (new — 7 templates as `@Provides @IntoSet @Named("promptTemplate")` functions)
- `app/src/main/java/com/warped/di/PromptLabTaskModule.kt` (new — `@Module @InstallIn(ViewModelComponent::class) object` with the @IntoSet bindings + a provider for the `Set<PromptTemplate>`)

## Implementation

### 1. `domain/prompt/PromptTemplate.kt`
```kotlin
data class PromptTemplate(
    val id: String,
    val name: String,
    val description: String,
    val systemPrompt: String,
    val userPromptTemplate: (Map<String, String>) -> String,
    val outputMarkdown: Boolean = true,
    val requiresLanguage: Boolean = false,
)
```

### 2. `domain/prompt/PromptTemplateConfigs.kt`
7 templates; each `internal fun provideXxxTemplate(): PromptTemplate = PromptTemplate(...)` annotated `@Provides @IntoSet @Named("promptTemplate")`.

Templates:
- `rewrite` — "Rewrite the following text in clearer, simpler language"
- `summarize` — "Summarize the following text in 3-5 sentences"
- `extractKeyPoints` — "Extract the 5 most important key points as a bulleted list"
- `codeExplain` — "Explain the following code step by step, line by line"
- `translate` — "Translate the following text to {language} (user-supplied)"
- `sentiment` — "Classify the sentiment of the following text as positive, neutral, or negative and explain why"
- `tableToJson` — "Convert the following table to a JSON array of objects"

### 3. `di/PromptLabTaskModule.kt`
```kotlin
@Module
@InstallIn(ViewModelComponent::class)
object PromptLabTaskModule {
    @Provides
    @ViewModelScoped
    @Named("promptTemplate")
    fun provideAllTemplates(set: Set<@JvmSuppressWildcards PromptTemplate>): Set<PromptTemplate> = set
}
```
`PromptTemplateConfigs.kt` is itself an `@Module @InstallIn(ViewModelComponent::class) object` that adds the per-template `@Provides @IntoSet @Named("promptTemplate")` methods.

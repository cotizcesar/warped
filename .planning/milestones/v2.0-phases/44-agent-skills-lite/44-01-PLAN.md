# Plan 44-01: Skills — domain + repository + 4 built-in skills (SKILLS-01, SKILLS-05, SKILLS-06)

**Phase:** 44 — Agent Skills Lite
**Requirements:** SKILLS-01, SKILLS-05, SKILLS-06

## Goal

Define the `Skill` value object, ship 4 built-in skills (Calculator, CurrentTime, JsonFormatter, Summarize), and provide a `SkillRepository` that exposes `enabledSkills: Flow<List<Skill>>` with DataStore-backed enable/disable.

## Implementation

### 1. `domain/skill/Skill.kt`
```kotlin
sealed class SkillCategory {
    data object Tool : SkillCategory()
    data object PromptTemplate : SkillCategory()
}

data class Skill(
    val id: String,
    val name: String,
    val description: String,
    val category: SkillCategory,
    val icon: String, // "calculate", "schedule", "code", "summarize"
    val promptPrefix: String? = null,
    val systemPrompt: String? = null,
)
```

### 2. `domain/skill/skills/*.kt`
4 skills:

- **CalculatorSkill** — category Tool, icon "calculate", description "Evaluate a math expression (e.g. `2 + 3 * 4`)." No promptPrefix.
- **CurrentTimeSkill** — category Tool, icon "schedule", description "Get the current date/time on this device." No promptPrefix.
- **JsonFormatterSkill** — category Tool, icon "code", description "Format, validate, and minify JSON." No promptPrefix.
- **SummarizeSkill** — category PromptTemplate, icon "summarize", description "Prepend a system prompt that turns the chat into a summarizer." `promptPrefix = "Summarize: "`, `systemPrompt = "You are a summarization specialist. ..."`.

### 3. `domain/skill/SkillRegistry.kt`
```kotlin
object SkillRegistry {
    val all: List<Skill> = listOf(
        CalculatorSkill,
        CurrentTimeSkill,
        JsonFormatterSkill,
        SummarizeSkill,
    )
}
```

### 4. `data/local/preferences/SkillPreferences.kt`
DataStore wrapper:
- `KEY_ENABLED_SKILLS: stringSetPreferencesKey("enabled_skills")`
- `enabledSkillIds: Flow<Set<String>>` (default = `SkillRegistry.all.map { it.id }.toSet()` for first-time users)
- `setSkillEnabled(id: String, enabled: Boolean)`

### 5. `domain/repository/SkillRepository.kt` + impl
- `enabledSkills: Flow<List<Skill>>` — joins the registry with the enabled-ids preference and emits ordered by name.
- `setEnabled(id: String, enabled: Boolean)` — delegates to the prefs.

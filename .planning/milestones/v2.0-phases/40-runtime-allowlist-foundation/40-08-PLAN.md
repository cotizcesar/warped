# Plan 40-08: EngineManager mmap-only cache + LRU eviction + trim memory

**Phase:** 40-runtime-allowlist-foundation
**Requirements:** CACHE-01, CACHE-02, CACHE-03
**Estimated files:** 2 created, 2 modified
**Estimated LOC:** ~250

## Goal
Stop copying model files into the cache. Use `EngineConfig.cacheDir` directly with a versioned, capped, LRU-evicted cache. Evict on critical memory pressure.

## Context
- **CACHE-01**: `EngineManager` no longer copies the model file; `EngineConfig.cacheDir = context.cacheDir.absolutePath/<version>` (namespaced by `BuildConfig.LITERTLM_VERSION`).
- **CACHE-02**: Cache directory is capped at 500MB with LRU eviction; cap is configurable via `AdvancedPreferences`.
- **CACHE-03**: `EngineManager.handleTrimMemory` evicts the cache when the device enters `TRIM_MEMORY_RUNNING_CRITICAL` or higher.

## Current State
- `EngineManager.switchToLiteRT()` copies the model file to `context.cacheDir/litertlm_cache/<fileName>` on first use, then re-uses the cache (saves 1-3GB/model + 3-10s cold start is the goal of CACHE-01).
- `EngineManager.handleTrimMemory(level)` only fires at `level >= 15` (TRIM_MEMORY_RUNNING_CRITICAL) and currently only deletes the cache directory recursively.
- `AdvancedPreferences` exists and can store a new key.

## Files to Create

### `app/src/main/java/com/warped/data/local/inference/LiteRtLmCacheManager.kt`
- `@Singleton class LiteRtLmCacheManager @Inject constructor(@ApplicationContext context: Context, advancedPreferences: AdvancedPreferences)`.
- API:
  - `val cacheRoot: File` — `context.cacheDir/litertlm/${BuildConfig.LITERTLM_VERSION}/`.
  - `fun cacheDirForModel(modelPath: String): File` — returns `File(cacheRoot, File(modelPath).name)`.
  - `suspend fun currentSizeBytes(): Long` — sums file lengths under `cacheRoot` (delegated to `Dispatchers.IO`).
  - `suspend fun ensureWithinCap()` — if `currentSizeBytes() > capBytes`, evict least-recently-accessed files until under cap.
  - `suspend fun evictAll()` — deletes all files under `cacheRoot`.
  - `suspend fun touchAccess(modelPath: String)` — updates `lastAccessTime` of the cached file (via `File.setLastModified`).
- LRU implementation: collect `(File, Long)` tuples, sort by lastModified ascending, delete from the front until under cap.
- Reads cap from `advancedPreferences.cacheMaxSizeBytes` (defaults to 500 * 1024 * 1024).

### `app/src/main/java/com/warped/data/local/preferences/AdvancedPreferences.kt` (modify)
- Add a new `cacheMaxSizeBytes: Flow<Long>` reading from a `longPreferencesKey("cache_max_size_bytes")` (default 500 * 1024 * 1024).
- Add `suspend fun setCacheMaxSizeBytes(bytes: Long)` to update.

## Files to Modify

### `app/src/main/java/com/warped/data/local/inference/EngineManager.kt`
- Inject `LiteRtLmCacheManager` (replace the manual `getCachedModelPath` logic).
- In `switchToLiteRT(modelPath)`:
  1. Compute `cacheRoot` via `cacheManager.cacheRoot` and ensure it exists.
  2. **No file copy.** Pass `modelPath` directly to `LiteRTLmEngine.init()` (the LiteRT-LM SDK mmap's the file, no copy needed).
  3. Call `cacheManager.touchAccess(modelPath)` after init.
- Remove the old `getCachedModelPath(modelPath)` private method.
- In `handleTrimMemory(level)`:
  - If `level >= 15` (TRIM_MEMORY_RUNNING_CRITICAL): unload current engine **and** call `cacheManager.evictAll()`.
  - Add a softer pre-eviction at `level >= 10` (TRIM_MEMORY_RUNNING_LOW): call `cacheManager.ensureWithinCap()`.

### `app/src/main/java/com/warped/data/local/inference/LiteRTLmEngine.kt`

## Verification
- `adb shell du -sh /data/data/com.warped.app/cache/litertlm/<version>/` shows zero usage after switching to mmap-only (no file copy).
- `cacheManager.currentSizeBytes()` returns the cap after a model is loaded (since LiteRT-LM mmap's the file, the model file size is reported by Android — but this is fine for our purposes; if the file is mmap'd, the kernel counts it against cache anyway).
- `handleTrimMemory(15)` causes `cacheManager.evictAll()` to run; `handleTrimMemory(10)` causes a soft pre-eviction to cap.
- No copy of the model file to `cacheDir/litertlm_cache/<name>` happens at any point (verified by `find /data/data/com.warped.app/cache -name "*.litertlm"` returning empty).

# Phase 1 — UI Design Contract

> Visual and interaction contract for the Android Compose frontend. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
> 
> **Adapted for:** Android Jetpack Compose + Material 3 (not web/shadcn).
> **Sources:** CONTEXT.md D-03, D-16, D-17; RESEARCH.md §1.2, §6; REQUIREMENTS.md PROV-01..05, CHAT-01..05.

## Design System

| Property | Value |
|----------|-------|
| Platform | Android (Kotlin + Jetpack Compose) |
| Design language | Material 3 (via `compose-bom:2025.04.00`) |
| Component library | `androidx.compose.material3` |
| Icon library | `androidx.compose.material:material-icons-extended` |
| Font | System default (Roboto on Android ≤12, Google Sans Text variable on Android 13+) |
| Theme strategy | Single `WarpedTheme` composable, dark-mode-first with light mode fallback |

**Theme composable:** `app/src/main/java/com/warped/ui/theme/Theme.kt`
**Supporting files:** `Color.kt`, `Type.kt`, `Shape.kt` in the same package.

## Spacing Scale

All values in density-independent pixels (`dp`). Multiples of 4 per Material 3 8dp grid.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4.dp | Icon-text gaps, inline chip padding, token spacing |
| sm | 8.dp | Compact element spacing, list item inner padding |
| md | 16.dp | Default element spacing, card padding, screen horizontal margins |
| lg | 24.dp | Section padding, vertical spacing between card groups |
| xl | 32.dp | Layout gaps between major regions |
| 2xl | 48.dp | Major section breaks, FAB bottom offset |
| 3xl | 64.dp | Page-level spacing (rarely used in Phase 1) |

**Icon touch targets:** All interactive icons and small buttons MUST use at least 48.dp × 48.dp minimum touch target size, per Android accessibility guidelines. Use `Modifier.size(48.dp)` on `IconButton` with `Icon` at 24.dp inside.

**Exceptions:** None. Standard 8dp grid applies to all Phase 1 UI.

## Typography

Four roles, two weights. Sizes in scalable pixels (`sp`).

| Role | Material 3 Token | Size | Weight | Line Height | Usage |
|------|-----------------|------|--------|-------------|-------|
| Body | `bodyLarge` | 16.sp | Regular (400) | 24.sp (1.5) | Chat message content, form field text, endpoint URLs |
| Label | `labelLarge` | 14.sp | Medium (500) | 20.sp (~1.43) | Buttons, chips, endpoint type badges, nav bar labels, timestamps |
| Heading | `headlineSmall` | 24.sp | Regular (400) | 32.sp (~1.33) | Screen titles, conversation titles, endpoint names in cards |
| Display | `displaySmall` | 36.sp | Regular (400) | 44.sp (~1.22) | Empty state headings, major section headers |

**Weights declared:** Regular (400) and Medium (500). No bold or semibold in Phase 1 — rely on size and color for hierarchy.

**Message role differentiation:** User messages use `bodyLarge` with Regular weight. Assistant (LLM) messages use `bodyLarge` with Regular weight. Role is differentiated by bubble color and alignment, NOT by font weight or size.

**Monospace exception:** Endpoint URLs and code snippets within chat responses use `androidx.compose.ui.text.font.FontFamily.Monospace` at `bodyMedium` (14.sp, Regular 400, 20.sp line height). This is the only typography exception.

### Dark Theme (Default — matches LM Studio desktop convention)

60/30/10 split applied to Material 3 color roles.

| Role | M3 Token | Hex Value | Usage |
|------|----------|-----------|-------|

| | `background` | `#0F0F1A` | Scaffold background |

| | `onPrimary` | `#0F0F1A` | Text/icon on primary buttons |

| | `onError` | `#0F0F1A` | Text/icon on error buttons |

**Accent reserved for explicit list (never "all interactive elements"):**
1. Send button (when input is non-empty)
2. FAB to add new endpoint
3. Selected navigation bar item (icon color + label color)
4. Switch/toggle "on" track
5. Connection test success status indicator
6. Focused input field border
7. Link-style text (model names, "tap to retry")
8. Primary tonal buttons ("Test Connection", "Save Endpoint", "Retry")

**Chat bubble colors (Role-specific, derived from the palette):**
| Role | Bubble Background | Bubble Text | Alignment |
|------|------------------|-------------|-----------|
| User | `primaryContainer` (`#2A2A50`) | `onPrimaryContainer` (`#C3C6FF`) | Right-aligned |
| Assistant | `surfaceVariant` (`#1C1C2E`) | `onSurface` (`#E2E2F0`) | Left-aligned |
| System | `surfaceContainer` (`#22223A`) | `onSurfaceVariant` (`#B0B0CC`) | Center-aligned, italic |
| Streaming | `surfaceVariant` (`#1C1C2E`) + blinking cursor in `tertiary` (`#56D4A8`) | `onSurface` (`#E2E2F0`) | Left-aligned |

## Shape

Material 3 shape tokens for Phase 1 components.

| Token | Value | Usage |
|-------|-------|-------|
| `extraSmall` | 4.dp | Chips, small badges |
| `small` | 8.dp | `EndpointCard`, `MessageBubble` |
| `medium` | 12.dp | `NavigationBar` (top corners), `TopAppBar` (bottom corners), dialogs |
| `large` | 16.dp | FAB, `ChatInputBar` container |
| `extraLarge` | 28.dp | `ModalBottomSheet` (future), large dialogs |

**Message bubbles:** `RoundedCornerShape(16.dp, 16.dp, 4.dp, 16.dp)` for assistant (left tail), `RoundedCornerShape(16.dp, 16.dp, 16.dp, 4.dp)` for user (right tail). The 4.dp corner creates the "speech bubble tail" effect on the appropriate side.

**Cards:** `EndpointCard` uses `RoundedCornerShape(12.dp)`.
**Input bar:** `RoundedCornerShape(28.dp)` for the text field container (pill shape).

## Copywriting Contract

### Primary CTA

| Screen | CTA Label | Action |
|--------|-----------|--------|
| Chat (idle) | **"Send"** | Send the typed message to the active provider/model |
| Chat (generating) | **"Stop"** | Cancel in-progress generation, preserve partial response |
| Endpoints (empty) | **"Add Endpoint"** | Open the endpoint creation form |
| Endpoint form (new) | **"Save Endpoint"** | Persist the new endpoint configuration |
| Endpoint form (edit) | **"Save Changes"** | Update the existing endpoint |

### Empty States

| Screen | Heading | Body |
|--------|---------|------|
| Chat — no conversations | **"No Conversations"** | "Add an endpoint, pick a model, and start chatting." |
| Chat — no endpoint selected | **"No Endpoint Selected"** | "Go to the Endpoints tab to add a remote provider." |
| Endpoints — empty list | **"No Endpoints"** | "Add an OpenAI-compatible, Ollama, LM Studio, or custom server to get started." |
| Models — empty list | **"No Models Available"** | "Select an active endpoint and tap refresh to list available models." |
| Conversation — no messages | **"Start a Conversation"** | "Type a message below to begin chatting with the selected model." |

### Error States

| Scenario | Heading | Body / Resolution |
|----------|---------|-------------------|
| Connection timeout | **"Can't Reach Server"** | "The server at {url} didn't respond. Check the URL, make sure the server is running, and try again." |
| Authentication failure (401) | **"Authentication Failed"** | "The API key for this endpoint was rejected. Check your key and update it in endpoint settings." |
| SSE stream lost | **"Connection Lost"** | "The streaming connection was interrupted. Your partial response has been saved. Tap Retry to reconnect." |
| General server error (5xx) | **"Server Error"** | "The server returned an error (HTTP {code}). This is usually temporary — wait a moment and try again." |
| Invalid URL format | **"Invalid URL"** | "The URL you entered doesn't look right. Include the protocol (http:// or https://)." |
| Model not found | **"Model Not Available"** | "The selected model '{modelName}' couldn't be found on this endpoint. It may have been removed or renamed." |

### Destructive Actions

| Action | Button Label | Confirmation Dialog |
|--------|-------------|---------------------|
| Delete endpoint | **"Delete Endpoint"** (in red) | Title: "Delete Endpoint?" / Body: "This will remove '{endpointName}' and your stored API key. This can't be undone." / Confirm: "Delete" (red) / Cancel: "Keep" |
| Delete conversation | **"Delete Chat"** | Title: "Delete Conversation?" / Body: "All messages in '{conversationTitle}' will be permanently removed." / Confirm: "Delete" (red) / Cancel: "Keep" |
| Remove API key | **"Remove Key"** (inline, not destructive red) | Title: "Remove API Key?" / Body: "You'll need to enter it again to use this endpoint." / Confirm: "Remove" / Cancel: "Keep Key" |

### Inline Status Messages

| Context | Copy |
|---------|------|
| Testing connection (in progress) | "Testing..." with `CircularProgressIndicator` (16.dp) |
| Connection test success | "Connected in {latency}ms" with `tertiary` check icon |
| Connection test failure | "Connection failed: {reason}" with `error` warning icon |
| Model list loading | "Loading models..." with `CircularProgressIndicator` (16.dp) |
| Model list empty | "No models found on this endpoint" |
| Generation stopped by user | "Generation stopped" as a system message in the chat |

## Interaction Contracts

### Chat Screen — Streaming Behavior
1. User types message → Send button transitions from `onSurfaceVariant` (disabled) to `primary` (active) when text is non-empty.
2. On send: user message appears as right-aligned bubble with 300ms fade-in animation. Input field clears. Send button becomes Stop button (icon swap: `Send` → `Close`).
3. Assistant streaming bubble appears left-aligned. Tokens appear with `AnimatedVisibility` 200ms fade-in each, batched at 50ms intervals (per PITFALLS.md §3.1).
4. Blinking cursor (`tertiary` colored `|` character) blinks at 500ms interval at end of streaming content.
5. `LazyColumn` auto-scrolls to bottom only when user is within 3 items of the bottom. If scrolled up, a "↓ New messages" FAB appears (per PITFALLS.md §3.4).
6. On `StreamToken.Done`: blinking cursor removed, assistant message becomes a permanent `MessageBubble`.
7. On Stop: partial content preserved as permanent assistant message with "(stopped)" system annotation.

### Endpoints Screen — Add/Test Flow
1. FAB "Add Endpoint" opens `EndpointForm`.
2. Form fields: Name (required), URL (required, validated for http/https prefix), Provider Type (dropdown: OpenAI / Ollama / LM Studio / Custom), API Key (optional, obscured by `PasswordVisualTransformation`).
3. "Test Connection" button sends HEAD/GET request. Shows inline spinner → success indicator with latency or error message.
4. "Save Endpoint" persists to Room, shows `Snackbar` confirmation: "Endpoint saved".
5. Long-press on `EndpointCard` reveals "Edit" and "Delete" context menu options.

### Navigation Bar
1. 3 items: Chat, Endpoints, Models. Chat is the start destination.
2. Selected item: icon + label in `primary` color. Unselected: `onSurfaceVariant`.
3. Settings gear icon in TopAppBar (Chat screen only for Phase 1). Navigates to Settings placeholder.
4. Navigation uses `saveState = true` / `restoreState = true` to preserve scroll position per tab.

### Error Display
1. Inline errors (connection lost, auth failed): `Snackbar` with `errorContainer` background, "Retry" action in `primary`.
2. Persistent errors (no endpoint, no model): full-screen empty state with `displaySmall` heading + `bodyLarge` description + "Add Endpoint" tonal button.
3. SSE errors: `ErrorBanner` composable at bottom of `LazyColumn` with "Connection Lost" message and "Retry" button.

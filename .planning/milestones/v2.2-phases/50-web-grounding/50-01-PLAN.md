## must_haves

<truths>
- "First http(s) URL in the message triggers exactly one fetch; 2nd+ URLs are ignored"
- "Fetch is bounded: 64KB byte cap, 3-redirect max, 8s connect / 10s read / 20s call timeouts, browser User-Agent, text/html+text/plain only"
- "Fetch is cancelable via Stop and new-turn pre-cancel, runs on Dispatchers.IO, never blocks the UI thread"
- "Offline short-circuits to the model-only path without opening a socket"
- "Fetched HTML becomes a [WEB CONTEXT] block truncated to a 4000-char line-boundary budget with [truncado] marker"
- "Instruction-like fetched lines are stripped and delimiter collisions escaped so content cannot hijack the model"
- "Fetch failures inject zero bytes as context; 64KB-cap truncation still grounds with the marker"
- "Grounding is current-turn prefix augmentation (prompt → block → original) for local and remote paths; LlmModelHelper unchanged; Room transcript keeps original text with no migration"
- "Grounded answers cite [1]/[2]; the model asks the user to paste a link when freshness is needed and never invents URLs"
- "Grounding toggle persisted in DataStore, default ON; toggle OFF skips detection entirely (pre-50 behavior)"
- "Zero new dependencies: audit-dependencies.sh green, no Jsoup import"
</truths>

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Inline code horizontal padding, copied-check gap, list block vertical rhythm |
| sm | 8px | Code text area padding, block vertical gaps (arrangement) |
| md | 16px | Reserved default element spacing (not used by code surfaces this phase) |
| lg | 24px | Section padding (Settings preset rows) |
| xl | 32px | Layout gaps; line-number gutter width (32dp), collapse bar height (32dp) |
| 2xl | 48px | Major section breaks (not used by code surfaces this phase) |
| 3xl | 64px | Page-level spacing (not used by code surfaces this phase) |

Exceptions (locked by existing `CodeBlock.kt` implementation — not changed by this phase):
- `10.dp` vertical padding on the code-block `Surface` (existing rhythm, kept as-is)
- `12.dp` header horizontal padding, `28.dp` header bar height, `12.dp` expansion overlay text sizes
- `1.dp` gutter divider width; `150.dp` collapsed max height; `40.dp` expand overlay height

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 14sp | Regular (400) | 1.5 |
| Label | 12sp | Medium (500) | 1.33 (16sp) |
| Heading | 14sp | Medium (500) | 1.5 |
| Display | 13sp | Regular (400) | 1.38 (18sp) |

Notes (locked existing behavior, not changed by this phase):
- `Display` row = code text: 13sp base × `codeFontScale` (Settings), line height 18sp × scale.
- `Label` row = header language label, line numbers, "Show less", "Copied!" confirmation.
- Expand affordance "Show all N lines" renders 14sp Medium (Body size/weight) — no fifth size introduced.
- Bold/Italic markdown emphasis (`**bold**`, `*italic*`) and the deprecated `CodeTheme` enum are
  pre-existing and out of scope; exactly 2 weights (400 + 500) are declared for this phase's surfaces.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | Material 3 `colorScheme.surface` / chat background | Chat bubbles, screen background |
| Secondary (30%) | Theme preset BACKGROUND token (e.g. Monokai `#272822`, One Dark `#282C34`, GitHub `#0D1117`/`#FFFFFF`, Dracula `#282A36`) | Code-block surface, header bar (surface darkened 8%), inline-code chip at 25% alpha |
| Accent (10%) | Preset token colors (KEYWORD / STRING / FUNCTION / etc. per preset) | Syntax token text inside code blocks only |
| Destructive | N/A — no destructive actions in this phase | — |

Accent reserved for: syntax-token text spans inside fenced code blocks; Settings selected-preset
check indicator; copy-success green `#4CAF50` ("Copied!" state); syntax-warning amber `#E6A817`.
Accent is never applied to buttons, nav, or general interactive elements.

Theme-application contract (the fix — THEME-01):
- Selecting Monokai / One Dark / GitHub / Dracula in Settings visibly changes the BACKGROUND,
  PLAIN, KEYWORD, STRING, COMMENT, NUMBER, FUNCTION, TYPE, OPERATOR, PROPERTY, CONSTANT,
  PUNCTUATION, and TAG colors of chat fenced code blocks (all 13 token types per preset).
- Monokai remains the default and the fallback for unknown keys (`fromKey` → MONOKAI).
- No palette edits: preset hex values are locked since v1.6.
- Verification guide: Python code block, each of the 4 presets, in both system light and dark mode.
- Streaming preserved: flat monospace (PLAIN color, no token colors) while `isStreaming`, full
  highlight applied when the fence closes.

## UI Considerations

Applicable state considerations resolved: 6 covered, 1 backstop, 0 unresolved.

| Category | Element(s) | Status | Resolution / Reason |
|----------|------------|--------|---------------------|
| empty | Fenced code block with blank content | ✅ covered | Blank code renders the documented "(empty)" copy; copy button disabled |
| loading | Fenced code block while tokens resolve | ✅ covered | Flat monospace in PLAIN color until `highlighter.highlight` returns on `Dispatchers.Default` |
| error | Highlight failure / >500KB cap / syntax heuristic | ✅ covered | Flat-monospace fallback with no error text (see Copywriting Contract error row); amber warning icon + tooltip when the heuristic fires |
| populated | Closed-fence code block, any of 4 presets | ✅ covered | Full 13-token highlight in the selected preset; theme switch animates token colors over 400ms (`FastOutSlowInEasing`) |
| overflow | Long lines; ≥15-line blocks | ✅ covered | Horizontal scroll for long lines; collapse at 150dp max with "Show all N lines" overlay, "Show less" when expanded |
| long-text | Code block exceeding 500KB | ✅ covered | Highlighting skipped by safety cap, flat monospace rendered, warning logged |
| partial | Streaming (unclosed fence) | 🧪 backstop | Flat monospace during stream, full highlight on fence close — covered by a visual UI-state test across open/closed fence states |

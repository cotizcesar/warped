## Key Deliverables

1. **llama.cpp as git submodule** with CMake integration building `libwarped_llama.so` for arm64-v8a + x86_64
2. **JNI bridge** with real llama.cpp model loading, progress callbacks, and thread-safe inference loop
3. **GGUF file browsing** on Hugging Face with quantization parsing and RAM estimates per file
4. **Download integrity validation** (GGUF magic + header) with corrupt file cleanup
5. **Pre-load RAM checks** with device-specific warning dialog
6. **Streaming token-by-token chat** via `callbackFlow` with stop support and TPS display
7. **Vulkan GPU backend** with CMake compilation and runtime detection with CPU fallback
8. **Cross-engine UX parity** with unified model management, metadata display, and RAM badges

## Tech Debt

- llama.cpp submodule pinned to latest commit (not a tagged release) — update policy needed
- CMake build not verified in actual Android NDK environment (requires local build)
- Vulkan GPU testing requires physical Snapdragon 8 Gen 2+ devices — deferred to device testing
- Inference loop uses greedy sampler; full sampler chain (temperature, top_p, top_k) structured but not yet parameterized from Kotlin
- Chat template auto-detection from GGUF metadata deferred to v2
